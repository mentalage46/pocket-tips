# 아날로그 입력과 PWM

ADC는 전압을 숫자로 읽고, DAC는 숫자를 전압으로 출력합니다. PWM은 디지털 출력의 켜져 있는 시간 비율을 바꿉니다.

먼저 알면 좋은 개념: [ADC·DAC·PWM과 측정 용어](../glossary/signals.md#변환과-측정), [샘플링과 측정 오차](../background/sampling-and-error.md), [ADC 입력의 충전 시간](../background/capacitance-and-timing.md)

## ADC: 전압을 숫자로 읽기

**양자화**는 연속적인 전압을 유한한 숫자 단계로 나누는 과정입니다. **Vref**는 변환의 기준 전압이며, 여기서 **1 LSB**는 코드 한 단계에 해당하는 전압 크기입니다.

N비트 ADC는 보통 `0`부터 `2^N - 1`까지의 코드를 출력합니다. 이상적인 단극성 ADC의 양자화 간격은 대략 `Vref / 2^N`입니다.

```text
12비트, 기준 전압 3.3V인 이상적 ADC
코드 범위: 0 ~ 4095
1 LSB ≈ 3.3 / 4096 ≈ 0.806mV
raw = 2048이면 입력 전압 ≈ 2048 × 3.3 / 4096 = 1.65V
```

실제 환산은 ADC의 전달 함수·보정식에 따릅니다. 끝점에 맞춰 `2^N - 1`로 나누는 환산도 있으므로, 해상도만 보고 식을 결정하지 않습니다. 게인·감쇠 설정이 있으면 입력 범위도 달라집니다.

### 측정값이 흔들리는 이유

- 기준 전압이나 전원이 흔들립니다.
- 배선이 길거나 모터·스위칭 전원에서 노이즈가 유입됩니다.
- 입력의 소스 저항이 커서 ADC 샘플링 커패시터가 충분히 충전되지 않습니다.
- 센서 자체의 잡음·오차가 있습니다.

해상도 12비트가 정확도 12비트를 보장하지는 않습니다. 기준 전압 오차, 비선형성, 보정 상태를 함께 고려합니다.

## 샘플링

샘플링 주파수는 1초에 읽는 횟수입니다. 대역 제한된 신호를 복원하려면 신호의 최고 주파수보다 두 배를 초과하는 샘플링이 필요하며, 실제 설계에는 여유와 아날로그 안티앨리어싱 필터가 필요합니다.

온도처럼 느린 신호와 진동처럼 빠른 신호는 필요한 샘플링 속도가 다릅니다. 이미 앨리어싱된 데이터는 읽은 뒤 평균을 내는 것만으로 원래 신호를 복구할 수 없습니다.

## PWM: 켜짐 비율 바꾸기

```text
주기 T = 1 / 주파수 f
듀티비 D = 켜져 있는 시간 / 주기

주파수 1kHz → 주기 1ms
듀티비 25% → HIGH 0.25ms, LOW 0.75ms
```

출력이 이상적으로 0V와 3.3V를 오간다면 시간 평균은 `3.3 × D`입니다. 하지만 핀에서 나오는 신호는 여전히 펄스이며, 안정된 아날로그 전압과 같지 않습니다.

| 용도 | 확인할 조건 |
| --- | --- |
| LED 밝기 | 깜빡임, 카메라 줄무늬, 전류 제한 |
| 모터 속도 | 드라이버 지원 주파수, 스위칭 손실, 가청 소음 |
| RC 서보 | 프레임 주기와 펄스 폭 사양 |
| 필터를 거친 평균 전압 | 리플, 응답 시간, 부하 영향 |

PWM 주파수와 분해능은 타이머 클록·분주 설정에 따라 서로 제약을 줄 수 있습니다. 같은 타이머를 공유하는 채널은 주파수 변경의 영향을 함께 받을 수 있습니다.

## DAC와의 차이

DAC는 코드에 대응하는 아날로그 레벨을 출력합니다. 출력 범위·구동 전류·정착 시간에 제한이 있으며, 모든 MCU가 DAC를 제공하지는 않습니다. PWM으로 아날로그 전압을 만들려면 적절한 필터와 경우에 따라 버퍼가 필요합니다.
