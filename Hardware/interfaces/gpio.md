# GPIO

GPIO(General-Purpose Input/Output)는 핀을 디지털 입력 또는 출력으로 사용하는 기능입니다.

먼저 알면 좋은 개념: [논리 레벨·고임피던스·플로팅](../glossary/signals.md#논리-신호), [풀업과 출력 구동](../background/pullups-and-drive.md)

## 입력과 출력

| 모드 | 동작 | 예시 |
| --- | --- | --- |
| 입력 | 핀 전압을 논리값으로 읽음 | 버튼, 센서의 인터럽트 신호 |
| 출력 | 핀을 HIGH 또는 LOW로 구동 | LED, 드라이버 제어 신호 |
| 입력 + 풀업/풀다운 | 입력에 기본 논리값을 부여 | 열려 있는 스위치 입력 |

HIGH가 정확히 전원 전압이고 LOW가 정확히 0V인 것은 아닙니다. 수신기의 입력 임계값과 송신기의 출력 특성을 비교해야 합니다.

## 플로팅과 풀업·풀다운

입력 핀은 일반적으로 임피던스가 높아 외부에서 상태를 정해주지 않으면 노이즈에 따라 값이 바뀔 수 있습니다. **높은 입력 임피던스**는 입력으로 흘러드는 전류가 매우 작다는 뜻으로 이해하면 됩니다. 이를 플로팅이라고 합니다.

```text
풀업 버튼 회로

논리 전원 ── 저항 ──┬── GPIO 입력
                   버튼
                    │
                   GND

버튼 놓음: HIGH
버튼 누름: LOW (active-low)
```

- **active-low**는 LOW일 때 기능이 활성화된다는 뜻입니다. 이 버튼 회로에서는 LOW를 “눌림”으로 해석합니다.
- 풀업은 기본값을 HIGH로, 풀다운은 LOW로 만듭니다.
- 내부 풀업·풀다운의 지원 여부와 저항 범위는 보드마다 다릅니다.
- 외부 저항은 입력 누설 전류·노이즈·소비 전류를 고려해 선택합니다. 10kΩ은 흔한 예일 뿐 고정 규칙은 아닙니다.
- GPIO를 출력 HIGH로 설정한 채 버튼으로 GND에 직접 연결하면 과전류가 흐를 수 있습니다. 버튼 입력은 입력 모드로 설정합니다.

## 버튼 디바운싱

기계식 접점은 한 번 누를 때 짧게 여러 번 붙었다 떨어집니다. 매 변화마다 이벤트를 만들면 한 번의 입력이 여러 번 처리됩니다.

다음은 **후보 상태가 일정 시간 유지되면** 입력을 확정하는 의사코드입니다.

```text
시작:
    후보 = 버튼 읽기
    확정 = 후보
    후보_시작 = 현재 시각

반복:
    raw = 버튼 읽기
    now = 현재 시각

    raw != 후보 이면:
        후보 = raw
        후보_시작 = now

    후보 != 확정 이고 경과시간(now, 후보_시작) >= 안정화_시간 이면:
        확정 = 후보
        확정 == LOW 이면 버튼_눌림_이벤트 발생
```

안정화 시간은 스위치와 요구 응답 속도에 맞춥니다. 예를 들어 20ms에서 시작해 실제 동작을 확인할 수 있습니다. 빠른 펄스나 회전 엔코더에 같은 값을 그대로 적용하면 정상 신호를 놓칠 수 있습니다.

## 출력 초기 상태

LED는 active-high 또는 active-low 회로일 수 있습니다. 출력값과 실제 장치의 켜짐 상태를 구별합니다.

리셋 중 핀은 입력·고임피던스 상태일 수 있으므로, 모터의 enable 같은 신호는 외부 저항으로 안전한 기본 상태를 만듭니다. 출력 래치를 미리 설정한 뒤 출력 모드로 바꿀 수 있는지는 MCU 문서를 확인합니다.
