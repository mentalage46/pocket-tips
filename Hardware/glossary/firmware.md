# 보드와 펌웨어 용어

[전체 용어 색인](./README.md)

## 보드와 실행 환경

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| MCU / Microcontroller Unit | CPU·메모리·주변장치를 한 칩에 통합한 마이크로컨트롤러입니다. |
| SBC / Single-Board Computer | 프로세서와 메모리 등을 한 보드에 구성한 컴퓨터입니다. |
| 펌웨어 / Firmware | 장치 내부에서 하드웨어를 초기화하고 제어하는 소프트웨어입니다. |
| RTOS / Real-Time Operating System | 정해진 시간 요구를 충족하도록 작업 실행을 관리하는 운영체제입니다. 사용 자체가 모든 작업의 시간 보장을 뜻하지는 않습니다. |
| GPIO / General-Purpose Input/Output | 범용 디지털 입출력 기능입니다. 핀별 지원 기능·전압·전류 제한이 있습니다. |
| 핀 멀티플렉싱 / Pin multiplexing, Pin mux | 하나의 핀에 연결할 내부 기능을 선택하는 것입니다. 보통 GPIO와 통신 기능 등을 골라 사용합니다. |
| 출력 래치 / Output latch | 출력할 값을 보관하는 회로입니다. 핀의 실제 전압이나 입력 읽기 값과 구분합니다. |

관련 문서: [보드와 핀맵](../basics/boards-and-pinouts.md), [GPIO](../interfaces/gpio.md)

## 데이터와 레지스터

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 레지스터 / Register | 여기서는 장치의 설정·상태·데이터를 표현하는 접근 지점입니다. CPU의 연산용 레지스터와 문맥을 구분합니다. |
| 비트 마스크·필드 / Bit mask, Bit field | 마스크는 특정 비트를 선택하는 패턴이고, 필드는 하나의 의미로 묶인 비트 구간입니다. |
| MSB·LSB / Most·Least Significant Bit | 각각 최상위·최하위 비트입니다. 바이트 순서 문맥에서는 Byte를 뜻하기도 하고, 측정에서 1 LSB는 코드 한 단계의 크기를 뜻하기도 합니다. |
| 엔디언 / Endianness | 여러 바이트로 된 값을 메모리에 배치하는 순서입니다. 통신선의 비트 순서·바이트 순서는 별도로 확인합니다. |
| 2의 보수·부호 확장 / Two's complement, Sign extension | 2의 보수는 부호 있는 정수 표현 방식입니다. 이 표현에서 폭을 늘릴 때 최상위 부호 비트를 복제하면 값을 유지할 수 있습니다. |
| 원시 값 / Raw value | 아직 단위 환산이나 보정 등을 적용하지 않은 데이터입니다. 바이트 순서·부호·스케일을 알아야 해석할 수 있습니다. |
| RO·WO·RW / Read Only, Write Only, Read/Write | 레지스터의 읽기 전용·쓰기 전용·읽기/쓰기 접근 속성입니다. 부작용과 예약 비트 규칙도 별도로 확인합니다. |
| W1C / Write One to Clear | 1을 쓰면 해당 상태 비트가 지워지는 속성입니다. 일반 변수의 비트 설정 방식으로 다루면 다른 상태를 지울 수 있습니다. |
| 읽으면 지워짐 / Read-to-clear | 읽는 동작 자체가 상태를 지우는 속성입니다. 디버거의 조회도 영향을 줄 수 있습니다. |
| 예약 비트 / Reserved bit | 사용자가 임의로 의미를 부여하면 안 되는 비트입니다. 쓰기 값과 보존 여부는 데이터시트 지시를 따릅니다. |
| 읽기-수정-쓰기 / Read-modify-write, RMW | 현재 값을 읽고 일부를 바꿔 다시 쓰는 과정입니다. 읽기와 쓰기 사이에 상태가 바뀌면 갱신을 잃을 수 있습니다. |
| volatile | 컴파일러가 대상 접근을 일반 변수처럼 생략하지 않도록 하는 데 쓰이는 지정자입니다. 원자성이나 상호 배제를 보장하지 않습니다. |

관련 문서: [레지스터와 비트 연산](../firmware/registers-and-bitwise.md), [레지스터 접근의 부작용](../background/register-side-effects.md)

## 시간과 동시성

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 폴링 / Polling | 반복해서 상태를 확인하는 방식입니다. 확인 간격보다 짧은 이벤트는 놓칠 수 있습니다. |
| 인터럽트·ISR / Interrupt, Interrupt Service Routine | 이벤트에 반응해 실행 흐름을 바꾸는 기능과 그 처리 루틴입니다. ISR은 길게 대기하지 않도록 설계합니다. |
| 원자성 / Atomicity | 다른 실행 흐름이 중간 상태를 관찰하거나 끼어들어 깨뜨릴 수 없는 하나의 동작처럼 수행되는 성질입니다. |
| 임계 구역·상호 배제 / Critical section, Mutual exclusion | 임계 구역은 공유 자원 접근을 보호해야 하는 코드 구간이고, 상호 배제는 여러 실행 흐름이 동시에 들어가지 못하게 하는 방법입니다. |
| 경쟁 상태 / Race condition | 여러 실행 흐름이나 하드웨어의 동작 순서에 따라 결과가 달라지는 문제입니다. |
| 블로킹 / Blocking | 작업이 끝나거나 조건이 충족될 때까지 현재 실행 흐름이 기다리는 방식입니다. 다른 모든 작업이 멈춘다는 뜻은 아닙니다. |
| 타임아웃 / Timeout | 정해진 시간 안에 완료되지 않으면 대기를 끝내고 실패 등으로 처리하는 제한입니다. |
| 상태 머신 / State machine | 현재 상태와 이벤트에 따라 다음 동작·상태를 정하는 구조입니다. 측정 대기·읽기·오류 처리를 나누는 데 유용합니다. |
| 래핑 / Wraparound | 고정 폭 카운터 등이 최댓값 다음에 0으로 돌아가는 현상입니다. |
| 단조 시간 / Monotonic time | 달력 시각 보정처럼 뒤로 바뀌지 않는 경과 시간 기준입니다. 표현에 사용한 고정 폭 카운터의 래핑은 별도로 처리해야 합니다. |
| 워치독 / Watchdog | 일정 시간 안에 정상 동작 확인을 받지 못하면 리셋 등 복구 동작을 수행하는 장치입니다. |

관련 문서: [시간과 상태 관리](../firmware/timing-and-state.md), [레지스터 접근의 부작용](../background/register-side-effects.md)
