# 신호와 측정 용어

[전체 용어 색인](./README.md)

## 논리 신호

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 논리 레벨 / Logic level, HIGH·LOW | 전압을 디지털 값으로 해석한 상태입니다. HIGH와 LOW는 각각 허용되는 전압 범위이며 정확히 한 전압을 뜻하지 않습니다. |
| 임계값 / Threshold | 입력을 HIGH나 LOW로 판단하는 경계입니다. 두 판정 범위 사이에서는 논리 상태가 보장되지 않을 수 있습니다. |
| 입력·출력 전압 규격 / VIH, VIL, VOH, VOL | VI는 입력 전압, VO는 출력 전압이고 H/L은 HIGH/LOW입니다. 최솟값·최댓값과 부하 조건을 함께 비교합니다. |
| 노이즈 여유 / Noise margin | 출력이 보장하는 전압과 입력 판정 경계 사이의 여유입니다. 신호가 흔들려도 정상 판정할 수 있는 범위와 관련됩니다. |
| 고임피던스 / High impedance, Hi-Z | 핀이 외부 회로로 전류를 거의 공급하거나 받아들이지 않는 상태입니다. LOW를 출력하는 것과 다릅니다. |
| 플로팅 / Floating | 입력 전압을 정해 주는 경로가 없어 상태가 불안정한 상황입니다. 고임피던스 입력도 외부 저항으로 전압을 정하면 플로팅을 피할 수 있습니다. |
| 풀업·풀다운 / Pull-up, Pull-down | 저항 등으로 신호의 기본 상태를 각각 HIGH·LOW로 정하는 방법입니다. |
| 푸시풀·오픈드레인 / Push-pull, Open-drain | 푸시풀은 HIGH와 LOW를 직접 구동합니다. 오픈드레인은 LOW로 당기거나 출력을 해제하며, HIGH를 만들려면 풀업 등이 필요합니다. |
| 활성 레벨 / Active-high, Active-low | 기능이 활성화되는 논리 상태입니다. active-low 리셋은 LOW일 때 리셋이 걸린다는 뜻입니다. |
| 레벨 시프터 / Level shifter | 서로 다른 논리 전압의 회로 사이에서 신호 전압을 바꾸는 회로입니다. 방향·속도·출력 방식이 용도와 맞아야 합니다. |
| 차동 신호 / Differential signal | 두 신호선 사이의 전압 차이로 정보를 전달하는 방식입니다. 허용 공통 모드 전압 등 수신기의 조건도 지켜야 합니다. |

관련 문서: [GPIO](../interfaces/gpio.md), [신호 전압](../interfaces/logic-levels.md), [풀업과 출력 구동](../background/pullups-and-drive.md)

## 시간과 파형

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 클록 / Clock | 회로가 동작이나 데이터 읽기 시점을 맞추는 데 사용하는 반복 신호입니다. |
| 에지 / Edge | 신호가 LOW에서 HIGH로 바뀌는 상승 에지 또는 반대로 바뀌는 하강 에지입니다. |
| 상승 시간 / Rise time | 신호가 정해진 낮은 전압에서 높은 전압까지 올라가는 데 걸리는 시간입니다. 10~90%, 30~70% 등 측정 기준을 확인해야 합니다. |
| 주기·주파수 / Period, Frequency | 주기는 한 번 반복하는 시간, 주파수는 1초당 반복 횟수입니다. 주파수의 단위는 헤르츠(Hz)이고 `f = 1/T`입니다. |
| 펄스 폭·듀티비 / Pulse width, Duty cycle | 펄스 폭은 한 펄스가 유지되는 시간, 듀티비는 한 주기 중 지정한 활성 구간의 비율입니다. |
| 셋업·홀드 시간 / Setup, Hold time | 데이터를 읽는 기준 시점 전·후에 데이터가 안정되어 있어야 하는 최소 시간입니다. |
| 디바운싱 / Debouncing | 기계식 접점이 짧게 여러 번 붙고 떨어지는 바운스를 한 번의 입력으로 처리하는 방법입니다. |
| 리플·정착 시간 / Ripple, Settling time | 리플은 전압 등에 남는 주기적 흔들림이고, 정착 시간은 변화 후 목표값의 허용 오차 범위에 들어가 유지될 때까지의 시간입니다. |

관련 문서: [정전용량과 신호 타이밍](../background/capacitance-and-timing.md), [아날로그와 PWM](../interfaces/analog-and-pwm.md)

## 변환과 측정

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| ADC / Analog-to-Digital Converter | 아날로그 입력을 디지털 숫자로 변환하는 회로입니다. 측정 가능 범위와 기준 전압을 확인합니다. |
| DAC / Digital-to-Analog Converter | 숫자에 대응하는 아날로그 전압·전류를 출력하는 회로입니다. |
| PWM / Pulse-Width Modulation | 펄스 폭을 바꾸는 방식입니다. 고정 주기에서는 듀티비를 바꿔 LED나 모터의 평균 출력을 조절할 수 있습니다. |
| 기준 전압 / Reference voltage, Vref | ADC나 DAC가 값 변환의 기준으로 삼는 전압입니다. 공급 전압과 같을 수도, 별도일 수도 있습니다. |
| 샘플링 / Sampling | 연속적인 신호를 특정 시점마다 읽는 과정입니다. |
| 양자화 / Quantization | 연속적인 크기를 유한한 단계의 숫자로 나타내는 과정입니다. ADC에는 시간 방향의 샘플링과 크기 방향의 양자화가 모두 있습니다. |
| 해상도·정확도 / Resolution, Accuracy | 해상도는 표현 가능한 단계의 세밀함이고, 정확도는 기준값에 얼마나 가까운지입니다. 높은 비트 수만으로 정확도를 보장하지 않습니다. |
| 앨리어싱 / Aliasing | 샘플링 결과만으로 서로 다른 주파수 성분을 구별할 수 없게 되는 현상입니다. 빠른 변화가 느린 변화처럼 보일 수 있습니다. |
| 안티앨리어싱 필터 / Anti-aliasing filter | 샘플링 전에 입력의 높은 주파수 성분을 줄여 앨리어싱을 억제하는 필터입니다. |
| 전달 함수 / Transfer function | 여기서는 입력 물리량과 출력 코드·전압 사이의 관계를 뜻합니다. 시스템의 주파수 응답을 나타낼 때도 쓰이는 말입니다. |
| 오프셋·게인 / Offset, Gain | 오프셋은 값에 더해지는 치우침, 게인은 입력 변화에 대한 출력 변화의 비율입니다. |
| 감쇠 / Attenuation | 신호 크기를 줄이는 것입니다. ADC 앞에서 감쇠하면 측정 범위를 넓힐 수 있지만 실제 입력 한계와 환산식을 확인해야 합니다. |
