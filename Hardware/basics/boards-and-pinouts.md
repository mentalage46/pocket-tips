# 보드와 핀맵

보드의 제품명, 칩 이름, 핀 번호는 서로 다른 정보를 나타냅니다.

먼저 알면 좋은 개념: [MCU·SBC·RTOS](../glossary/firmware.md#보드와-실행-환경), [고임피던스](../glossary/signals.md#논리-신호)

## MCU와 SBC

| 구분 | MCU 기반 보드 | SBC |
| --- | --- | --- |
| 중심 구성 | CPU, 메모리, 주변장치를 한 칩에 통합한 마이크로컨트롤러 | 프로세서와 메모리 등을 갖춘 소형 컴퓨터 |
| 실행 환경 | 펌웨어 직접 실행 또는 RTOS | 일반적으로 Linux 같은 OS |
| 주 용도 | 센서 읽기, 타이밍 제어, 저전력 제어 | 네트워크, 저장, 영상 처리, 복잡한 애플리케이션 |
| 타이밍 | 하드웨어 타이머·인터럽트 활용 | 일반 사용자 공간 코드는 스케줄링 지연의 영향 |

SBC에서도 전용 주변장치나 보조 MCU로 정밀 제어를 할 수 있습니다. 분류만으로 성능을 단정하지 말고 필요한 주변장치와 시간 제약을 기준으로 선택합니다.

## 세 가지 핀 표기

- **물리 핀 번호**: 보드 커넥터에서 몇 번째 위치인지 표시합니다.
- **GPIO 번호 또는 포트명**: 칩의 논리적 신호 이름입니다.
- **보드 별칭**: 보드가 정의한 디지털·아날로그 핀 이름입니다.

예제의 숫자 `5`가 물리 핀 5번인지 GPIO 5번인지 먼저 확인해야 합니다. 같은 제품군도 보드 버전이나 패키지에 따라 핀 배치가 달라질 수 있습니다.

## 핀 기능과 멀티플렉싱

하나의 핀이 GPIO, UART, SPI, 타이머 출력 등 여러 기능을 가질 수 있습니다. **핀 멀티플렉싱**은 이 핀에 연결할 내부 기능을 선택하는 것입니다. 해당 핀에서 사용할 수 있는 대체 기능과 설정 방법을 확인합니다.

| 확인 항목 | 이유 |
| --- | --- |
| 전원·GND·신호 핀 구분 | 전원 핀은 소프트웨어로 바꿀 수 있는 GPIO가 아님 |
| 입력 전용 여부 | 모든 핀이 출력 가능한 것은 아님 |
| ADC·PWM 지원 | 보드의 모든 핀에서 지원하지 않을 수 있음 |
| 부팅 설정 핀 | 외부 저항이나 모듈이 부팅 모드를 바꿀 수 있음 |
| 디버그·플래시 연결 | 다른 기능으로 사용하면 업로드·디버깅에 영향 |
| 초기 상태 | 리셋 중 입력·고임피던스 상태가 되어 출력 장치가 오동작할 수 있음 |
| 전압 허용 범위 | 일부 핀만 5V 내성이 있거나 특정 동작 모드에서 제한될 수 있음 |

## 연결표 작성 예시

실제 배선 전에 다음 정보를 보드와 모듈 문서에서 찾아 기록합니다.

| 보드 쪽 정보 | 모듈 쪽 정보 | 추가 확인 |
| --- | --- | --- |
| 허용 출력 전류가 충분한 전원 핀 | VCC 또는 VIN | 레귤레이터 유무, 공급 전압 |
| GND | GND | 절연 여부 |
| 선택한 I2C 주변장치의 SDA 핀 | SDA | 핀 대체 기능, 풀업 전압 |
| 선택한 I2C 주변장치의 SCL 핀 | SCL | 핀 대체 기능, 풀업 전압 |

보드의 핀맵 그림만으로 부족하면 보드 회로도와 MCU 데이터시트를 함께 봅니다.
