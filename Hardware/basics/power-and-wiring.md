# 전원과 배선

코드가 맞아도 전원이 부족하거나 기준 전압이 다르면 장치는 불안정하게 동작합니다.

먼저 알면 좋은 개념: [정격·레귤레이터·역급전](../glossary/electrical.md#전압과-전원), [전원과 노이즈](../background/power-and-noise.md)

## 전원 전압과 전류 용량

- **전압**은 보드와 모듈의 허용 범위에 맞춥니다.
- **전류 용량**은 전원이 공급할 수 있는 최대치입니다. 정상 부하는 필요한 전류를 가져가므로 5V 2A 전원이라고 항상 2A가 흐르는 것은 아닙니다.
- 평균 소비 전류 외에 시작·송신·모터 기동 때의 피크 전류를 고려합니다.
- 보드의 전원 출력 핀은 USB 전원·레귤레이터·보호 소자의 제한을 받습니다.

예를 들어 보드 150mA와 센서 두 개가 각각 20mA를 소비한다면 기본 합계는 190mA입니다. 여기에 다른 부하와 순간 피크, 전원 및 레귤레이터의 여유를 반영해 공급 장치를 선택합니다.

## GPIO는 전원 핀이 아니다

GPIO 한 핀의 허용 전류와 포트·칩 전체의 허용 전류는 다를 수 있습니다. 절대 최대 정격까지 사용해도 된다는 뜻은 아닙니다.

- 작은 LED도 전류 제한 저항과 GPIO 구동 사양을 확인합니다.
- 모터·릴레이 코일은 GPIO로 직접 구동하지 않습니다.
- 신호 출력으로 다른 보드의 전원을 공급하지 않습니다.

## 공통 GND

절연되지 않은 GPIO·UART·I2C·SPI 연결에서는 송신자와 수신자가 같은 기준 전압을 사용해야 합니다.

```text
보드 GPIO ───────── 모듈 신호 입력
보드 GND ──┬────── 모듈 GND
외부 전원 - ┘
외부 전원 + ────── 모듈 전원 입력
```

외부 전원과 보드 전원의 양극을 무조건 연결하는 것은 아닙니다. GND 공유와 전원 출력 병렬 연결은 다른 일입니다. 절연 통신 모듈은 제조사 회로에 따라 절연 경계를 유지합니다.

모터의 큰 전류가 센서의 GND 경로를 따라 흐르면 기준 전압이 흔들릴 수 있습니다. 여기서 **리턴 경로**는 부하로 간 전류가 전원으로 돌아오는 경로입니다. 큰 부하의 전원·리턴 경로를 짧게 배치하고 민감한 신호 경로와 분리합니다.

## 배선 순서

1. 전원을 끄고 모듈의 정확한 모델·핀맵을 확인합니다.
2. 공급 전압과 논리 전압을 각각 확인합니다.
3. GND, 전원, 신호선을 연결하고 극성과 단락을 점검합니다.
4. 필요한 풀업·저항·드라이버와 디커플링을 연결합니다.
5. 가능하면 전류 제한이 가능한 전원으로 시작하고, 전원 핀에서 실제 전압을 측정합니다.
6. 부하가 작동할 때도 전압이 유지되는지 확인합니다.

## 흔한 실수

| 증상 또는 상황 | 확인할 점 |
| --- | --- |
| 모터 시작 시 보드 재부팅 | 기동 전류, 전압 강하, 배선 저항, 노이즈 |
| 브레드보드 한쪽만 동작 | 전원 레일이 중간에서 끊겨 있는지 확인 |
| 외부 전원과 USB 동시 사용 | 보드가 해당 조합을 지원하는지, 역급전 경로가 있는지 확인 |
| 꺼진 모듈에 GPIO 신호 입력 | 입력 보호 경로로 전원이 유입될 수 있으므로 전원 순서와 핀 사양 확인 |
| 선이 뜨거워지거나 과전류 발생 | 즉시 전원을 끄고 단락·극성·부하 정격 확인 |
