# Automation

PLC를 중심으로 산업 자동화 제어를 정리한 가이드입니다. PLC 구조와 스캔 사이클부터 IEC 61131-3 프로그래밍, 산업 통신, HMI·SCADA, 기능 안전과 OT 보안, 제조사별 차이까지 다룹니다.

본문은 특정 제조사에 종속되지 않는 개념을 먼저 설명하고, 제조사마다 다른 주소 체계·도구·제품 정보는 [vendors](./vendors/README.md)에 모읍니다. 전압·전류·옴의 법칙 같은 전기 기초는 [Hardware](../Hardware/README.md) 문서를 참고합니다.

> 안전 관련 문서는 학습용 정리입니다. 실제 설비의 안전 설계는 해당 표준, 법규, 자격을 갖춘 안전 담당자의 검토를 따릅니다.

## 추천 실습 순서

실습은 시뮬레이터나 교육용 트레이너에서 시작합니다. 실제 설비에서 온라인 편집이나 강제(force) 출력을 하기 전에 정지 상태와 비상정지 동작을 먼저 확인합니다.

| 단계 | 실습 | 확인할 개념 | 성공 기준 |
| --- | --- | --- | --- |
| 1 | 버튼으로 램프 켜기 | 입력·출력 주소, a/b 접점, 스캔 사이클 | 버튼을 누르는 동안만 램프가 켜짐 |
| 2 | 시작·정지 자기유지 회로 | 자기유지, 정지 우선, b접점 정지 버튼 | 시작 후 손을 떼도 유지되고 정지로 꺼짐 |
| 3 | 타이머·카운터 | TON·TOF, CTU, 리셋 조건 | 정한 시간·횟수에 맞춰 동작 |
| 4 | 모터 정역 운전 | 인터록, 듀얼 코일 금지 | 정·역 출력이 동시에 켜지지 않음 |
| 5 | 3단계 시퀀스(상태 머신) | 스텝 전이, 타임아웃, 알람 | 단계가 순서대로 넘어가고 타임아웃 시 알람 |
| 6 | Modbus TCP로 값 읽기 | 레지스터 주소, 워드 순서 | PC 도구에서 PLC 값을 읽고 단위를 맞춤 |
| 7 | HMI 화면 연결 | 태그, 알람, 권한 | 정상 상태는 회색, 이상 상태만 색으로 표시 |
