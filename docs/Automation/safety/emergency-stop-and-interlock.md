# 비상정지와 인터록

비상정지, 가드 인터록, 라이트 커튼, 드라이브의 STO는 현장에서 가장 자주 만나는 안전 기능입니다. 이 문서는 각 장치의 원칙과 배선·구성 방식, 안전 거리 계산의 구조, 흔한 실수를 정리합니다. PL·SIL·카테고리 개념은 [기능 안전 기초](./functional-safety.md)를 먼저 읽습니다.

> 학습용 정리입니다. 실제 설계·개조는 표준 원문, 장치 제조사 매뉴얼, 국내 법령(산업안전보건법, 산업안전보건기준에 관한 규칙), 자격을 갖춘 안전 담당자의 검토를 따릅니다. 이 문서의 공식과 수치로 실제 설치 거리를 정하지 않습니다.

## 1. 비상정지 원칙 (ISO 13850)

현행판은 **ISO 13850:2015(3판)** 이며, 4판 작업 초안(WD)이 진행 중입니다. 전기·전자 구현은 IEC 60204-1이 다룹니다.

| 원칙 | 내용 |
| --- | --- |
| 보완 방호 조치 | 비상정지는 실제 또는 임박한 위험을 피하기 위한 기능입니다. 가드, 인터록, 안전 기능을 **대신하지 않습니다** |
| 항상 사용 가능 | 모든 운전 모드에서 동작하고, 다른 기능보다 우선합니다 |
| 정지 카테고리 | 정지 카테고리 **0 또는 1**로 동작합니다(2는 비상정지에 쓰지 않음) |
| 래칭(latching) | 누르면 기계적으로 잠겨 리셋할 때까지 정지 명령을 유지합니다. 전기식 장치는 직접 개로 동작(direct opening action, IEC 60947-5-5) 접점을 씁니다 |
| 리셋 ≠ 재기동 | 비상정지 장치를 풀어도(리셋해도) 기계가 스스로 다시 움직이면 안 됩니다. 리셋은 재기동을 **허용**할 뿐이고, 재기동은 별도 시작 조작으로 합니다 |
| 색과 표시 | 작동부는 **적색**, 배경이 있으면 **황색**. 버섯형 푸시버튼이 대표적이며 줄(로프) 스위치, 페달 형태도 있습니다 |
| 배치 | 운전자와 위험에 노출될 수 있는 사람이 빠르게 닿을 수 있는 곳 |

```text
비상정지 누름 ──▶ 정지(카테고리 0 또는 1) ──▶ 래칭 유지
비상정지 해제(돌려서 복귀) ──▶ 아직 정지 상태
리셋 버튼(에지 감지) ──▶ 안전 회로 준비 완료
시작 버튼 ──▶ 그때서야 운전 재개
```

## 2. 정지 카테고리 (IEC 60204-1)

현행판은 **IEC 60204-1:2016(6판) + AMD1:2021** 통합판입니다.

| 카테고리 | 동작 | 비상정지 사용 |
| --- | --- | --- |
| 0 | 액추에이터 전원을 즉시 차단하는 **비제어 정지**. 모터는 관성으로 서거나 기계 브레이크로 섬 | 가능 |
| 1 | 동력을 유지한 채 **제어 정지**(감속)하고, 정지한 뒤 전원 차단 | 가능 |
| 2 | 제어 정지 후에도 **전원을 유지** | 비상정지에 쓰지 않음. 운전 모드 전환 등 일반 정지용 |

- 카테고리 0은 단순하지만 관성이 큰 축은 오래 돌거나 낙하할 수 있습니다. 수직축은 브레이크와 함께 설계합니다.
- 카테고리 1은 드라이브의 SS1(감속 후 STO) 기능이나 안전 릴레이의 지연 출력으로 구현합니다.

## 3. 안전 릴레이 동작

안전 릴레이(safety relay)는 비상정지·도어 스위치 신호를 감시하고 출력 접촉기를 제어하는 전용 모듈입니다.

```text
           ┌──────────── 안전 릴레이 ────────────┐
 E-stop CH1 ──▶ S11-S12      교차 감시       13-14 ──▶ K1 코일 ─┐
 E-stop CH2 ──▶ S21-S22   (채널 불일치 검출)  23-24 ──▶ K2 코일 ─┤
                                                               │
 리셋 버튼 + EDM ──▶ S33-S34 ◀── K1 NC ── K2 NC ◀──(강제 가이드 보조접점)
           └───────────────────────────────────┘
 K1, K2 주접점 직렬 ──▶ 모터 전원
 (단자 번호는 제조사마다 다름)
```

| 기능 | 의미 |
| --- | --- |
| 듀얼 채널 | 입력을 2채널로 받아 한 채널의 단선·접점 용착이 있어도 다른 채널로 정지 |
| 교차 감시 | 두 채널이 함께 바뀌는지, 채널 간 단락이 없는지 검사. 불일치하면 재기동 차단 |
| 피드백 루프(EDM) | External Device Monitoring. 출력 접촉기 K1·K2의 강제 가이드(mirror) 보조 NC 접점을 리셋 회로에 넣어, 접촉기가 용착돼 떨어지지 않았으면 리셋되지 않게 함 |
| 수동 리셋 | 사람이 위험 구역 밖에서 상황을 확인하고 누름. 버튼을 누른 채 고정하는 오용을 막기 위해 **신호 에지(누름→뗌)** 를 감시합니다(ISO 13849-1:2023) |
| 자동 리셋 | 입력이 정상으로 돌아오면 바로 준비 완료. 사람이 위험 구역에 들어갈 수 없는 구조(예: 몸 전체가 들어갈 수 없는 가드)에서만 씁니다 |

- 접촉기는 정격·수명 데이터(B10D)가 있는 제품을 쓰고, 보조 접점은 주접점과 기계적으로 연동되는 미러 접점이어야 EDM이 의미가 있습니다.
- 안전 릴레이는 단순하고 검증이 쉬워 안전 기능이 몇 개 안 되는 기계에 적합합니다. 안전 기능이 많거나 존(zone)별 정지가 필요하면 안전 PLC를 검토합니다(경험칙).

## 4. 안전 PLC, 안전 I/O, 안전 통신

안전 PLC는 이중 처리, 자기 진단, 안전 전용 태스크를 갖춘 PLC이고, 안전 I/O는 입력 채널 테스트 펄스, 출력 리드백 같은 진단을 내장한 I/O입니다. 사용 원칙은 [기능 안전 기초 7장](./functional-safety.md)을 봅니다.

안전 통신은 **블랙 채널** 방식이 일반적입니다. 일반 산업 네트워크(케이블, 스위치)는 믿지 않고, 안전 계층이 일련번호, 타임아웃(watchdog), CRC, 송수신자 식별로 손실·지연·위조·순서 뒤바뀜을 검출합니다. 이 개념은 IEC 61784-3 시리즈(기능 안전 필드버스 프로파일)에 정리돼 있습니다.

| 안전 프로토콜 | 기반 네트워크 | 관리 단체 |
| --- | --- | --- |
| PROFIsafe | PROFIBUS, PROFINET | PI (PROFIBUS & PROFINET International) |
| CIP Safety | EtherNet/IP, DeviceNet (IEC 61784-3-2) | ODVA |
| FSoE (Safety over EtherCAT) | EtherCAT (IEC 61784-3-12) | EtherCAT Technology Group |
| CC-Link IE 안전 통신 기능 | CC-Link IE 계열. IEC 61508 SIL 3 요구 충족, IEC 61784-3 개념 준수 | CLPA |

- CC-Link IE TSN의 안전 기능을 따로 부르는 공식 명칭은 확인하지 못했습니다(미확인). CLPA 사이트는 "CC-Link IE 안전 통신 기능"으로 소개합니다.
- 안전 통신을 쓰면 응답 시간 계산에 통신 watchdog 시간이 들어갑니다. 라이트 커튼 안전 거리 계산의 T가 길어질 수 있습니다.
- 네트워크 자체는 [산업용 이더넷](../communication/industrial-ethernet.md)을 참고합니다.

## 5. 인터록 장치 (ISO 14119)

가드가 열리면 위험한 동작을 멈추고, 닫힐 때까지 시작하지 못하게 하는 장치입니다. 현행판은 **ISO 14119:2024(3판, 2024-09)** 입니다.

| 타입 | 작동 방식 | 예 | 무력화 쉬움 |
| --- | --- | --- | --- |
| 1 | 비코드 기계식 | 캠 작동 리밋 스위치, 힌지 스위치 | 드라이버로 눌러도 닫힌 것처럼 보임 |
| 2 | 코드 기계식 | 혀(tongue) 모양 액추에이터 스위치 | 예비 액추에이터로 우회 가능 |
| 3 | 비코드 비접촉식 | 유도형 센서, 일반 자석 + 리드 스위치 | 쇳조각·자석으로 우회 가능 |
| 4 | 코드 비접촉식 | RFID, 코드 자석 | 짝이 되는 액추에이터만 인식 |
| 5 | 트랩 키(trapped key) 시스템 | 키가 있어야 가드를 열 수 있고, 가드가 열려 있으면 키가 빠지지 않음 | 2024판에서 부속서 K로 편입 |

- 2013판의 코드 수준 구분은 낮음(1–9가지), 중간(10–1000가지), 높음(1000가지 초과)입니다(벤더 해설, 2013판 기준). 코드 수준이 높을수록 예비 액추에이터로 우회하기 어렵습니다.
- 2024판 주요 변경: 트랩 키 시스템을 타입 5로 편입(이전 ISO/TS 19837), 결함 마스킹 기준(이전 ISO/TR 24119)을 부속서 J로 편입, 위치 스위치를 기계적 스토퍼로 쓰지 않을 것 등.

### 무력화 방지

ISO 14119의 핵심 목표 중 하나는 **합리적으로 예견 가능한 무력화(defeat)를 최소화**하는 것입니다. ISO 13849-1:2023도 안전 기능을 무력화할 동기를 줄이도록 요구합니다.

- 먼저 **왜 우회하고 싶어지는지**를 봅니다. 셋업·청소 때마다 가드를 열어야 하는데 정지·재기동이 오래 걸리면 결국 우회됩니다. 안전한 저속 모드, 보조 접근구, 빠른 재기동을 설계에 넣습니다.
- 우회 수단을 어렵게 만듭니다: 숨겨진 설치, 코드 수준 높은 액추에이터, 비분리형 고정(일방향 나사, 리벳), 개폐 횟수와 신호 타당성 감시.

### 가드 잠금(guard locking)

정지 시간이 접근 시간보다 길면(예: 큰 관성 회전체) 가드가 열리는 순간 멈춰도 늦습니다. 이때 가드 잠금을 씁니다.

| 방식 | 동작 | 특징 |
| --- | --- | --- |
| 스프링 잠금, 전원으로 해제 | 전원이 없으면 잠김 | 정전 시에도 잠김 유지. 사람이 갇히지 않도록 비상 해제 수단 필요 |
| 전원으로 잠금, 스프링 해제 | 전원이 없으면 풀림 | 정전 시 열림. 위험이 남아 있으면 부적합할 수 있음 |

- 인터록(가드 위치 감시)과 가드 잠금(잠금 상태 감시)은 **별개의 안전 기능**이며 각각 PLr을 정합니다.
- 잠금 해제 조건은 "정지 확인(속도 0 감시 또는 충분한 시간 지연)"으로 둡니다.

## 6. 라이트 커튼과 안전 거리 (ISO 13855)

라이트 커튼은 빛이 가려지면 정지 신호를 냅니다. 신호를 받은 뒤 기계가 멈출 때까지 사람이 위험점에 닿지 않도록 **충분히 떨어뜨려** 설치해야 합니다.

현행판은 **ISO 13855:2024(3판, 2024-11)** 이며 제목에서 "접근 속도(approach speeds)"가 빠졌습니다. 2024판에서 계산식이 바뀌었으므로 예전 자료의 공식을 그대로 쓰지 않습니다.

| 판 | 기본식 | 비고 |
| --- | --- | --- |
| 2010판(폐지) | S = K × T + C | S 최소 거리, C = 침입 거리(검출 능력 d에 따른 값) |
| 2024판 | **S = K × T + DDS + Z** | S는 "분리 거리(separation distance)"로 이름이 바뀜. DDS는 보호 장치별 도달 거리, Z는 측정 오차·브레이크 마모 등 추가 거리 |

| 기호 | 뜻 |
| --- | --- |
| K | 접근 속도. 상지(팔) 2000 mm/s 또는 보행 1600 mm/s (조건은 원문) |
| T | 전체 정지 시간 = 보호 장치 응답 + 안전 로직·통신 응답 + 기계 정지 시간. 2024판은 T 결정 절차(5.4)가 훨씬 자세해짐 |
| DDS | 보호 장치의 도달(reach) 거리. 2010판의 C 대신 위·아래·사이로 손을 뻗는 경우를 나눠 봄 |
| Z | 보충 거리 |

계산 흐름 예시(2010판 기준 해설, 개념 이해용):

```text
1) K = 2000 mm/s로 먼저 계산
2) S가 500 mm보다 크면 K = 1600 mm/s로 다시 계산
3) 다시 계산한 S가 500 mm 이하이면 S = 500 mm
   (손가락·손 검출용, C = 8 × (d − 14) 를 쓰는 경우의 해설 예)
```

- 2024판 기준 값과 조건은 원문으로 확인합니다. 양수 조작 장치의 추가 거리, 라이트 커튼 아래로 기어 들어가는 경우, 뒤쪽으로 걸어 들어가는 경우(walk-behind) 등도 2024판에서 달라졌습니다.
- T는 **실측**합니다. 브레이크 마모로 정지 시간이 늘면 같은 위치에서도 안전 거리가 부족해집니다. 정지 시간 측정기를 써서 정기 점검합니다(경험칙).
- 라이트 커튼은 IEC 61496 타입도 확인합니다. 라이트 커튼(AOPD) 표준은 타입 2와 4만 정의하므로, PLr d가 필요하면 보통 타입 4를 씁니다(IFA 정리).
- 뮤팅(물체 통과 시 일시 무효화)은 사람과 물체를 구분하는 조건(센서 배치, 순서, 시간)을 갖춰야 하며, 뮤팅 로직도 안전 기능입니다.

## 7. 안전 토크 오프 STO (IEC 61800-5-2)

STO(Safe Torque Off)는 인버터·서보 드라이브가 **모터에 토크를 만드는 에너지를 공급하지 않게** 하는 안전 하위 기능입니다. 드라이브 안전 기능은 IEC 61800-5-2:2016이 정의합니다.

| 기능 | 동작 | 정지 카테고리 |
| --- | --- | --- |
| STO | 토크 발생 에너지 즉시 차단 | 0 |
| SS1 | 감속 후 STO | 1 |
| SS2 / SOS | 감속 후 정지 위치 유지(전원 유지) | 2 |
| SLS | 안전 제한 속도 | - |

- STO 입력은 안전 릴레이나 안전 PLC의 안전 출력으로 끊습니다. 일반 PLC 출력으로 구동하면 안전 기능이 아닙니다.
- STO를 쓰면 주 접촉기 없이도 정지 기능을 만들 수 있어 빠른 재기동과 접촉기 수명 문제를 줄입니다.
- STO는 **전기적 절연이 아닙니다**. 모터·드라이브 단자에는 여전히 위험한 전압이 있을 수 있으므로 전기 작업은 주 전원 차단과 잠금·표지(LOTO)를 합니다.
- 수직축·중력 부하는 STO만으로 위치를 유지하지 못합니다. 안전 브레이크 제어(SBC)와 기계 브레이크를 함께 씁니다.
- 드라이브 데이터시트의 STO 등급(SIL, PL, 카테고리)과 조건(테스트 펄스 허용, 배선 길이, 진단)을 그대로 따릅니다. 모터 구동은 [액추에이터 기초](../../Hardware/modules/actuator-basics.md)를 참고합니다.

## 흔한 실수

| 실수 | 왜 위험한가 | 바로잡기 |
| --- | --- | --- |
| 비상정지를 **일반 PLC 입력**으로만 받아 프로그램으로 출력을 끔 | PLC 고장, 프로그램 오류, 강제 출력, 통신 지연이면 정지하지 않음 | 안전 릴레이·안전 PLC로 하드웨어 차단 경로를 만들고, 일반 PLC에는 상태만 알림 |
| **소프트웨어만으로** 정지 (드라이브에 속도 0 명령) | 드라이브·통신 결함 시 정지 실패 | STO 또는 접촉기로 에너지 차단 |
| 시운전 때 **점퍼·브리지**로 도어 스위치를 우회하고 그대로 둠 | 가드가 열려도 기계가 동작 | 우회는 기록·표지·기한을 두고 관리하고, 인계 전 전수 확인 |
| 비상정지 해제만으로 기계가 다시 움직임 | 리셋과 재기동 혼동 | 리셋 후 별도 시작 조작 요구 |
| 단일 접촉기, EDM 없음 | 접점 용착 시 정지 불가를 모름 | 접촉기 2개 직렬 + 미러 접점 피드백 |
| 리셋 버튼이 위험 구역 안에서 보이지 않는 곳에 있음 | 다른 사람이 안에 있는데 리셋 | 위험 구역 전체가 보이는 바깥 위치에 설치 |
| 라이트 커튼을 거리 계산 없이 "적당히" 설치 | 손이 먼저 위험점에 닿음 | 실측 정지 시간으로 ISO 13855 계산, 정기 재측정 |
| 비상정지를 카테고리 2(전원 유지)로 구성 | 전원이 살아 있어 결함 시 재가동 가능 | 카테고리 0 또는 1 |
| 안전 기능을 HMI 화면 버튼으로 구현 | 터치 패널·통신 결함 시 동작 보장 없음 | HMI 비상정지 표시는 상태 표시용, 실제 비상정지는 하드와이어 장치 |

## 점검표

| 질문 |
| --- |
| 비상정지가 모든 운전 모드에서 동작하고, 정지 카테고리 0 또는 1인가 |
| 비상정지 장치가 적색·황색 배경이고 래칭되며, 리셋만으로 재기동하지 않는가 |
| 안전 회로가 듀얼 채널이고 교차 감시와 EDM 피드백이 있는가 |
| 수동 리셋이 에지 감지이고 위험 구역이 보이는 곳에 있는가 |
| 인터록 장치 타입과 코드 수준이 무력화 위험에 맞고, 우회 동기를 줄였는가 |
| 정지 시간이 접근 시간보다 길면 가드 잠금을 쓰는가 |
| 라이트 커튼 거리를 실측 T와 ISO 13855:2024 기준으로 계산하고 기록했는가 |
| 드라이브 정지에 STO를 쓰고, STO 입력을 안전 출력으로 끊는가 |
| 시운전용 점퍼·강제 출력이 인계 전에 모두 제거됐는가 |
