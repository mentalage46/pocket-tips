# I/O 결선과 신호

PLC 고장 문의의 상당수는 프로그램이 아니라 **결선** 문제입니다. 이 문서는 산업 현장에서 가장 흔한 24V DC 디지털 I/O, 싱크·소스, NPN/PNP 센서, 출력 종류, 서지 보호, 4–20mA 아날로그, 노이즈 대책과 배선 점검 순서를 다룹니다.

먼저 알면 좋은 개념: [전기 기초](../../Hardware/basics/electrical-basics.md), [기본 부품](../../Hardware/basics/components.md), [전원과 노이즈](../../Hardware/background/power-and-noise.md)

> 결선 작업은 전원을 차단하고 잠금·표지(LOTO)를 한 상태에서 합니다. AC 전원이 들어오는 단자대는 자격을 갖춘 사람이 작업합니다.

## 24V DC 디지털 입력

디지털 입력은 단자에 전류가 흐르는지(ON) 아닌지(OFF)를 읽습니다. 입력 내부에는 보통 포토커플러가 있어 현장 배선과 PLC 내부 회로를 절연합니다.

```text
   +24V ─── 스위치 ─── [입력 단자 X0] ── 저항 ── 포토커플러 LED ──┐
                                                               [COM] ─── 0V
   스위치 닫힘 → 전류가 흐름 → LED 켜짐 → PLC가 X0 = 1 로 읽음
```

### IEC 61131-2 입력 타입

IEC 61131-2는 PLC 장비 요구사항 표준이며, 24V DC 디지털 입력을 전압·전류 특성에 따라 Type 1, 2, 3으로 나눕니다. 현재 판은 **IEC 61131-2:2017** 4판이고, 2017판에서 음논리(negative logic) 디지털 입출력과 Type 3-d 입력 등이 추가됐습니다.

| 타입 | ON 영역 | OFF 영역 | 대상 |
| --- | --- | --- | --- |
| Type 1 | 15–30 V, 2–15 mA | 5 V 이하 (또는 15 V 이하이면서 0.5 mA 이하) | 기계 접점(버튼, 리밋 스위치), 3선식 센서 |
| Type 2 | 11–30 V, 6–30 mA | 5 V 이하 (또는 11 V 이하이면서 2 mA 이하) | 누설 전류가 큰 2선식 반도체 센서 |
| Type 3 | 11–30 V, 2–15 mA | 5 V 이하 (또는 11 V 이하이면서 1.5 mA 이하) | 2선·3선 센서, 저전력 |

- 수치는 Beckhoff 응용 노트(EN 61131-2 기준)가 정리한 표에서 옮긴 것입니다. 2017판 원문 표는 직접 확인하지 못했습니다(미확인). 설계에는 사용하는 입력 모듈 매뉴얼의 값을 씁니다.
- Type 3는 Type 2보다 발열이 적고 채널 밀도를 높일 수 있으며, Type 1·2 용도로도 쓸 수 있습니다. 입력 모듈 사양서에서 Type 1 또는 Type 3 표기를 흔히 볼 수 있습니다(경험칙).
- **2선식 센서**는 OFF 상태에서도 자기 동작용 누설 전류가 흐릅니다. 이 전류가 입력의 OFF 전류 한계보다 크면 센서가 꺼져 있어도 입력이 ON으로 읽힙니다. 2선식 센서를 쓸 때는 센서의 누설 전류와 입력 타입을 비교합니다.

### 입력 필터

입력 모듈은 접점 채터링과 노이즈를 거르는 필터 시간(예: 3 ms)을 가집니다. 필터가 길면 짧은 펄스를 놓치고, 짧으면 노이즈에 민감해집니다. 응답 시간 계산은 [스캔 사이클](./scan-cycle.md)에서 다룹니다.

## 싱크와 소스

**싱크**(sink)는 전류가 흘러 들어가는 쪽, **소스**(source)는 전류가 흘러 나오는 쪽입니다. 문제는 같은 단어를 **누구의 입장에서** 부르느냐가 제조사·지역마다 다르다는 점입니다.

| 기준 | "싱크 입력"의 뜻 | 공통(COM) 연결 | 맞는 센서 |
| --- | --- | --- | --- |
| 입력 단자 기준 (AutomationDirect 등, 미주·유럽 문서에 흔함) | 전류가 입력 단자로 **들어감** | COM → 0V | PNP(소스형) 센서 |
| 센서 출력 기준 (Mitsubishi 등 일본 제조사 문서) | 전류가 입력 단자에서 **나와** 센서로 빨려 들어감 | COM(S/S) → +24V | NPN(싱크형) 센서 |

같은 "싱크 입력"이 정반대 결선을 뜻할 수 있습니다. 예를 들어 Mitsubishi FX5 문서는 싱크 입력일 때 S/S 단자를 24V에, 소스 입력일 때 0V에 연결하라고 안내합니다. 반면 AutomationDirect는 싱크 입력을 "공통을 전원 (-)에 연결하는 입력"으로 설명합니다.

용어보다 **회로도**로 판단합니다.

```text
① COM이 0V에 연결된 입력 (입력 단자 기준 "싱크 입력")
   센서 출력이 +24V를 공급해야 ON → PNP 센서

   +24V ──[PNP 센서]── 출력 ──→ [X0] ─(입력회로)─ [COM] ── 0V

② COM이 +24V에 연결된 입력 (Mitsubishi 기준 "싱크 입력")
   센서 출력이 0V로 끌어내려야 ON → NPN 센서

   +24V ── [COM] ─(입력회로)─ [X0] ──→ 출력 ──[NPN 센서]── 0V
```

- 한국·일본 설비는 NPN 센서가, 유럽 설비는 PNP 센서가 많다고들 합니다(경험칙). 기존 설비를 따라가는 것이 정비에 유리합니다.
- IEC 61131-2의 기본 입력은 전류가 흘러 들어가는 형태이고, 반대 극성(음논리)은 2017판에서 추가됐습니다.
- 싱크·소스는 DC 회로에서만 의미가 있습니다. AC 입력에는 쓰지 않습니다.

## NPN·PNP 센서와 2선·3선

| 구분 | 결선 | 장점 | 주의 |
| --- | --- | --- | --- |
| 3선식 | 갈색(BN) +24V, 청색(BU) 0V, 흑색(BK) 출력 | 누설 전류가 거의 없음, 대부분의 입력과 호환 | 센서 전원이 필요해 배선 1가닥 추가 |
| 2선식 | 전원과 신호를 같은 2가닥으로 | 배선이 적고 기계 접점 자리에 그대로 교체 | OFF 누설 전류, ON 잔류 전압. 입력 타입 확인 필요 |
| NPN 출력 | 출력이 0V로 끌어내림(싱크형) | — | COM을 +24V에 두는 입력과 짝 |
| PNP 출력 | 출력이 +24V를 내보냄(소스형) | 출력선이 0V(접지)에 닿으면 OFF로 읽혀 안전 쪽으로 고장남. NPN은 같은 고장에서 ON으로 읽힘 | COM을 0V에 두는 입력과 짝 |

갈색·청색·흑색 배색은 EN 60947-5-2 표기를 따르는 근접센서 데이터시트에서 쓰입니다. 색만으로 NPN/PNP를 알 수는 없으니 모델명과 데이터시트를 확인합니다.

## 디지털 출력 종류

| 항목 | 릴레이 출력 | 트랜지스터 출력 | 트라이액(SSR) 출력 |
| --- | --- | --- | --- |
| 부하 전원 | AC·DC 모두 | DC만 | AC만 |
| 응답 속도 | 느림 (예: 약 10 ms) | 빠름 (예: 0.2 ms 이하) | 중간 (AC 반주기 영향) |
| 전류 용량 예 | 2 A/점 | 0.5 A/점 | 제품마다 다름 |
| 수명 | 접점 마모로 개폐 횟수 제한 | 반도체라 접점 마모 없음 | 반도체 |
| OFF 누설 전류 | 거의 없음 | 작음 | 있음. 작은 부하가 꺼지지 않을 수 있음 |
| 적합 | 전압이 다양한 부하, 낮은 개폐 빈도 | 솔레노이드 밸브, 고속 펄스, 잦은 개폐 | AC 솔레노이드, 히터 |

예시 수치는 Mitsubishi FX5UJ 사양서 기준입니다(릴레이 2 A/점·약 10 ms, 트랜지스터 0.5 A/점·0.2 ms 이하(Y3 이후)). 제품마다 점당 전류와 함께 **공통(COM)당 합계 전류** 한계가 있습니다.

- 트랜지스터 출력도 싱크(NPN)형과 소스(PNP)형이 있습니다. 부하를 +24V와 출력 사이에 두느냐, 출력과 0V 사이에 두느냐가 다릅니다.
- 릴레이 출력으로 1초에 여러 번 개폐하는 용도(펄스, PWM)는 수명이 금방 끝납니다. 트랜지스터 출력을 씁니다.
- 큰 모터나 히터는 출력이 직접 구동하지 않고 **전자 접촉기**(MC)나 SSR을 거칩니다. 출력 장치 일반은 [출력 장치 기초](../../Hardware/modules/actuator-basics.md)를 참고합니다.

## 유도성 부하와 서지 보호

릴레이 코일, 솔레노이드, 전자 접촉기 코일은 인덕턴스가 있어 전류를 끊는 순간 높은 역기전력이 생깁니다. 이 서지는 트랜지스터 출력을 파손하고 릴레이 접점을 빨리 마모시키며, 노이즈로 다른 입력을 오동작시킵니다.

| 방법 | 부하 | 특징 |
| --- | --- | --- |
| 다이오드(플라이백) | DC | 가장 효과적. 대신 부하의 복귀(OFF) 시간이 가장 길어짐. 극성 주의 |
| 다이오드 + 제너 | DC | 복귀 시간을 줄이면서 서지 억제 |
| 배리스터(MOV) | AC·DC | 전압을 일정 수준으로 제한. 복귀 시간이 조금 늘어남 |
| RC(CR) 스너버 | AC·DC | AC 부하에 적합. 커패시터 방전 전류가 접점에 흐르지 않게 결선 위치 주의 |

```text
DC 코일 + 플라이백 다이오드

   출력(+) ──┬──────────┐
             │          │
          코일(L)    다이오드 (캐소드가 + 쪽)
             │          │
   0V ───────┴──────────┘

다이오드를 반대로 달면 출력이 켜지는 순간 단락됩니다.
```

- Omron은 DC 부하에는 다이오드가, AC 부하에는 배리스터나 CR이 가장 효과적이라고 안내합니다.
- 보호 소자는 **부하(코일) 바로 옆**에 답니다. 서지 억제기가 내장된 코일·소켓 제품도 있습니다.
- 트랜지스터 출력 모듈 중에는 내부 보호 회로가 있는 제품도 있습니다. 매뉴얼에서 외부 보호 소자 필요 여부를 확인합니다.

## 아날로그 신호

| 신호 | 범위 | 장점 | 단점 |
| --- | --- | --- | --- |
| 전류 4–20 mA | 4 mA = 0%, 20 mA = 100% | 배선 저항·노이즈에 강함, 단선 감지(라이브 제로) | 루프 전압 예산 계산 필요 |
| 전류 0–20 mA | 0 mA = 0% | — | 0 mA와 단선을 구별할 수 없음 |
| 전압 0–10 V | 0 V = 0% | 결선이 간단 | 긴 배선에서 전압 강하·노이즈에 약함, 단선을 0%로 오인 |

### 라이브 제로와 고장 신호

4–20 mA는 0%가 0 mA가 아니라 4 mA이므로 **0 mA = 단선 또는 전원 이상**으로 판단할 수 있습니다. 이를 라이브 제로(live zero)라고 합니다. 4–20 mA 같은 직류 아날로그 신호는 IEC 60381-1에서 다룹니다.

공정 계측에서는 NAMUR NE 43 권고를 따르는 트랜스미터가 많습니다.

| 전류 | 의미 (NE 43) |
| --- | --- |
| 3.8–20.5 mA | 측정값 |
| 3.6 mA 이하 | 고장 (예: 단선, 센서 고장) |
| 21 mA 이상 | 고장 |

PLC 프로그램에서는 3.6 mA 이하·21 mA 이상을 측정값으로 쓰지 않고 알람으로 처리합니다. 실제 고장 출력값은 트랜스미터 설정으로 바뀔 수 있으니 계기 매뉴얼을 확인합니다.

### 2선식과 4선식 트랜스미터

| 방식 | 전원 | 결선 |
| --- | --- | --- |
| 2선식(루프 전원) | 신호선 2가닥으로 전원과 신호를 함께 | +24V → 트랜스미터 → 아날로그 입력 → 0V |
| 4선식(외부 전원) | 전원선 2가닥 별도, 트랜스미터가 전류를 능동 출력 | 전원 2선 + 신호 2선 |

```text
2선식 루프 전압 예산 (예시)

전원 24 V - 트랜스미터 최소 동작 전압 12 V = 남는 전압 12 V
최대 루프 저항 = 12 V ÷ 0.020 A = 600 Ω
→ 아날로그 입력 저항 + 배선 저항 + 표시계·배리어 저항의 합이 600 Ω 이하여야 함
```

트랜스미터 최소 동작 전압과 입력 저항은 제품마다 다르므로 매뉴얼 값으로 계산합니다. 아날로그 입력 카드가 "2선식 전원 공급형"인지 "외부 전원형"인지도 확인합니다. 잘못 연결하면 전류가 흐르지 않거나 입력 회로가 손상됩니다.

ADC·분해능 같은 아날로그 기초는 [아날로그와 PWM](../../Hardware/interfaces/analog-and-pwm.md)을 참고합니다.

## 공통(COM) 결선

입력·출력 단자는 여러 점이 하나의 COM을 공유하는 **공통 그룹**으로 묶여 있습니다.

| 지켜야 할 것 | 이유 |
| --- | --- |
| 한 그룹 안에서는 같은 전원·같은 극성 | 다른 전원을 섞으면 의도하지 않은 경로로 전류가 흐름 |
| 다른 전압(24V DC와 AC 220V)은 다른 그룹 | 절연 파괴, 감전 위험 |
| COM당 합계 전류 한계 확인 | 점당 한계를 지켜도 그룹 합계를 넘길 수 있음 |
| 0V(DC 공통)를 여러 전원 사이에 연결할지 설계 기준으로 결정 | 공통 기준이 없으면 신호 레벨이 맞지 않음. [전원과 배선](../../Hardware/basics/power-and-wiring.md) 참고 |

## a접점·b접점과 페일세이프

| 이름 | 영문 | 평상시 | 조작 시 |
| --- | --- | --- | --- |
| a접점 | NO(Normally Open) | 열림 | 닫힘 |
| b접점 | NC(Normally Closed) | 닫힘 | 열림 |
| c접점 | 전환(Changeover) | a·b를 함께 가진 접점 | — |

**정지·비상·리밋 신호는 b접점으로 결선**합니다. 선이 끊어지거나 단자가 빠지면 입력이 OFF가 되어 "정지"로 판단되므로, 고장이 안전한 쪽으로 드러납니다(페일세이프).

```text
정지 버튼을 b접점으로 결선한 경우

평상시: 정지 버튼 닫힘 → 입력 X1 = 1
누름  : 정지 버튼 열림 → 입력 X1 = 0
단선  : 입력 X1 = 0   → 누른 것과 같게 정지

프로그램:  ──[ 시작 ]──┬──[ X1 ]────( 운전 )
                     │      ↑ 래더에서는 a접점 명령으로 씀
           ──[ 운전 ]──┘
```

현장 b접점을 래더에서는 a접점 명령(`--[ ]--`)으로 쓴다는 점이 처음에 가장 헷갈립니다. "현장 접점 종류"와 "프로그램 명령 종류"를 따로 생각합니다. 단, 비상정지는 PLC 입력만으로 처리하지 않고 안전 회로로 구현합니다. [비상정지와 인터록](../safety/emergency-stop-and-interlock.md)을 참고합니다.

## 노이즈·접지·실드

| 대책 | 방법 |
| --- | --- |
| 배선 분리 | 동력선(모터, 인버터 출력)과 신호선(24V I/O, 아날로그, 통신)을 다른 덕트로. 교차는 직각으로(경험칙) |
| 실드 케이블 | 아날로그·통신·엔코더 선은 실드선(트위스트 페어) 사용 |
| 실드 접지 | 아날로그 신호는 한쪽 끝 접지를 기본으로 하는 경우가 많고, 고주파 노이즈가 큰 곳은 양쪽 접지와 등전위 본딩을 쓰기도 함. 제조사 설치 지침을 따름(경험칙) |
| 서지 억제 | 코일 부하에 다이오드·CR·배리스터 |
| 인버터 노이즈 | 인버터 출력선은 실드 모터 케이블, 노이즈 필터. 제조사 EMC 지침 준수 |
| 전원 분리 | PLC 제어 전원과 부하(솔레노이드·램프) 전원을 분리하면 부하 서지가 CPU에 덜 영향 |
| 접지 | 제어반 접지 바에 한 점으로 모으고, 접지선은 짧고 굵게 |

간헐적 오동작은 대부분 노이즈와 접촉 불량입니다. 신호 품질 진단은 [문제 진단](../../Hardware/debugging/troubleshooting.md)도 참고합니다.

## 배선 점검 순서

시운전 전에 아래 순서로 점검합니다. 앞 단계를 건너뛰고 전원을 넣으면 단락으로 모듈이 손상될 수 있습니다.

| 단계 | 상태 | 확인 |
| --- | --- | --- |
| 1 | 전원 OFF | 도면과 단자 번호 대조, 단자 조임, 전선 번호표 |
| 2 | 전원 OFF | 테스터로 +24V–0V 간 단락 여부, 동력선과 신호선 사이 단락 |
| 3 | 전원 OFF | 필요하면 절연 저항 측정(PLC·반도체 모듈은 분리한 뒤) |
| 4 | 제어 전원만 ON | 24V 전원 전압, 극성. PLC 전원 LED, 오류 LED |
| 5 | 프로그램 정지(STOP) | 입력 점검: 센서·버튼을 하나씩 동작시키며 입력 LED와 온라인 모니터 값 확인 |
| 6 | 동력 차단, 주변 안전 확보 | 출력 점검: 출력을 하나씩 강제(force)해 해당 부하만 동작하는지 확인. 끝나면 강제 해제 |
| 7 | 아날로그 | 신호 발생기·캘리브레이터로 4·12·20 mA를 넣어 스케일 값 확인 |
| 8 | 비상정지·인터록 | 비상정지·안전문이 모든 운동을 멈추는지 확인 |

출력 강제는 프로그램 인터록을 무시하므로, 설비가 움직이지 않는 상태와 주변 인원을 먼저 확인합니다.

## 흔한 실수

| 실수 | 증상 | 대책 |
| --- | --- | --- |
| NPN 센서를 PNP용 입력에 연결 | 센서 LED는 켜지는데 입력이 안 들어옴 | 입력 COM 결선과 센서 출력 형식을 맞춤 |
| 2선식 센서 누설 전류 | 센서가 꺼져도 입력이 ON 또는 깜빡임 | 입력 타입 확인, 블리더 저항(제조사 지침에 따라) |
| 플라이백 다이오드 역방향 | 출력 ON 순간 단락, 퓨즈·출력 소자 손상 | 캐소드를 + 쪽에 |
| 트라이액 출력으로 작은 부하 구동 | OFF인데 램프가 희미하게 켜짐 | 누설 전류 확인, 더미 부하 또는 릴레이 출력 |
| 0–10 V를 긴 거리 배선 | 값이 흔들리고 오차 | 4–20 mA로 바꾸거나 실드·배선 분리 |
| 정지 버튼을 a접점으로 결선 | 단선 시 정지가 안 됨 | 정지·비상은 b접점 |
| COM당 합계 전류 초과 | 여러 출력이 동시에 켜질 때 모듈 발열·손상 | 그룹 분산, 외부 릴레이 |
