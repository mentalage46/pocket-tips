## PLC 구성과 형태

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| PLC / Programmable Logic Controller | 센서·스위치 신호를 읽고 프로그램에 따라 모터·밸브·램프를 제어하는 산업용 컴퓨터입니다. 프로그램을 정해진 주기로 반복 실행하고, 노이즈·진동·온도 변화가 큰 제어반에서 오래 멈추지 않도록 설계됩니다. |
| 릴레이 반 / Relay panel | PLC 이전에 릴레이·타이머를 전선으로 연결해 순서 제어를 하던 제어반입니다. 래더 다이어그램이 릴레이 회로도를 닮은 이유가 이 역사에 있습니다. |
| 랙·베이스·백플레인 / Rack, Base, Backplane | 모듈을 꽂고 백플레인 버스로 서로 연결하는 틀입니다. 슬롯 수와 증설 가능 여부가 확장 한계를 정합니다. |
| 전원 모듈 / Power supply module | 백플레인과 모듈 내부 회로에 전원을 공급하는 모듈입니다. 센서·부하용 필드 24V는 보통 별도 전원으로 두고, 모듈을 늘리면 소비 전류 합계를 다시 계산합니다. |
| 디지털 입출력 / Digital Input·Output, DI·DO | ON/OFF 신호를 읽거나 부하를 켜고 끄는 모듈입니다. 입력은 전압·싱크/소스·필터 시간을, 출력은 출력 종류와 점당·공통당 전류를 확인합니다. |
| 아날로그 입출력 / Analog Input·Output, AI·AO | 전류·전압·온도 같은 연속 신호를 수치로 바꾸거나 수치를 신호로 내보내는 모듈입니다. 신호 범위, 분해능, 채널 간 절연을 확인합니다. |
| 원격 I/O / Remote I/O | I/O를 현장 가까이 두고 네트워크로 CPU와 연결하는 구성입니다. 배선은 짧아지지만 응답 시간 계산에 네트워크 갱신 주기가 더해집니다. |
| 일체형·모듈형 / Compact, Modular PLC | 일체형은 CPU·전원·I/O가 한 몸체이고, 모듈형은 랙에 필요한 모듈을 골라 꽂습니다. 일체형도 옆에 증설 모듈을 붙이는 제품이 많습니다. |
| 안전 PLC / Safety PLC | 이중화된 내부 구조와 자기 진단으로 안전 기능을 수행하는 PLC입니다. 일반 PLC에 안전 프로그램을 얹은 것이 아니며, 인증된 하드웨어·펌웨어와 작성 규칙을 함께 써야 합니다. |
| PAC / Programmable Automation Controller | PLC에 PC급 처리 능력·데이터 처리·다중 언어를 더한 제어기를 부르는 말입니다. PLC와의 경계는 마케팅 용어에 가깝습니다. |
| 소프트 PLC / Soft PLC | 산업용 PC의 실시간 OS·확장 위에서 PLC 런타임을 실행하는 형태입니다. 비전·데이터 처리와 제어를 한 장비에서 할 때 쓰며, OS 업데이트·보안 같은 IT 지식도 필요합니다. |
| 가상 PLC / Virtual PLC | PLC 런타임을 서버·엣지 장비의 가상 머신이나 컨테이너로 실행하는 형태입니다. 하이퍼바이저 설정이 실시간성에 직접 영향을 주고, I/O는 여전히 현장에 있어 네트워크 설계와 보안이 더 중요해집니다. |
| 이중화 / Redundancy | CPU·전원·네트워크를 2벌 두고 고장 시 대기 측이 이어받게 하는 구성입니다. CPU만 2개 둔다고 끝나지 않으며 전원, 네트워크 링, I/O 스테이션에 단일 고장점이 남았는지 확인합니다. |
| 정전 유지 영역 / Retentive memory, RETAIN | 전원이 꺼져도 값을 유지하는 메모리 영역입니다. 생산 수량·레시피는 유지하고, 운전 명령 비트는 유지하지 않는 편이 안전합니다. |

## 스캔과 실행

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 스캔 사이클 / Scan cycle | 입력을 읽고, 프로그램을 실행하고, 출력을 내보내는 과정을 전원이 켜져 있는 동안 반복하는 PLC 실행 모델입니다. 실제 단계 순서는 기종마다 달라서 Siemens S7-1500은 출력 이미지를 먼저 쓰고 입력을 읽은 다음 프로그램을 실행합니다. |
| 입력·출력 리프레시 / Input, Output refresh | 모든 입력 단자 상태를 입력 이미지로 한꺼번에 읽고, 출력 이미지를 출력 단자에 한꺼번에 반영하는 단계입니다. 프로그램을 실행하는 동안에는 실제 출력 단자가 바뀌지 않습니다. |
| 프로세스 이미지 / Process image, PII·PIQ | 입력 이미지(PII)와 출력 이미지(PIQ)를 담는 메모리로, 한 스캔 동안 입력 값을 고정합니다. 그래서 같은 스캔 안에서는 프로그램 위쪽과 아래쪽이 같은 입력 값을 봅니다. |
| 비동기 I/O 갱신 / Asynchronous I/O update | I/O 값이 프로그램 실행과 상관없이 I/O 구성에서 정한 주기(RPI)마다 갱신되는 방식입니다. Rockwell Logix 계열은 태스크 앞뒤에서 같은 입력 태그가 달라질 수 있어 로직 앞에서 버퍼 태그로 복사하거나 `CPS` 명령을 씁니다. |
| 스캔 타임 / Scan time, Cycle time | 스캔 한 바퀴에 걸리는 시간입니다. 프로그램 길이·통신량·인터럽트에 따라 매번 달라지므로 설계에는 최대값을 씁니다. |
| 응답 시간 / Response time | 입력이 바뀐 순간부터 출력 단자가 바뀔 때까지의 시간이며, 입력이 바뀐 시점에 따라 1–2스캔 사이에서 흔들립니다. 최악값은 입력 필터 + 2 × 스캔 타임 + 출력 지연으로 보고, 원격 I/O라면 네트워크 갱신 주기의 2배를 더합니다. |
| 입력 필터 / Input filter | 접점 채터링과 노이즈를 거르려고 입력 모듈이 두는 지연 시간입니다. 길면 짧은 펄스를 놓치고, 짧으면 노이즈에 민감해집니다. |
| 펄스 캐치 / Pulse catch | 입력 필터 + 1 스캔보다 짧은 펄스를 놓치지 않게 하는 입력 기능입니다. 인터럽트 입력과 함께 짧은 신호 대책으로 씁니다. |
| 고속 카운터 / High-Speed Counter, HSC | 엔코더처럼 kHz 단위로 들어오는 펄스를 스캔과 별도로 세는 기능입니다. 스캔으로 세면 펄스를 놓칩니다. |
| 워치독 / Watchdog | 스캔이 너무 오래 걸리면 PLC를 정지시키거나 오류 처리로 넘기는 감시 타이머입니다. 출력이 굳은 채 설비가 움직이는 상황을 막지만 안전 기능은 아닙니다. |
| 태스크 / Task | 프로그램을 언제 실행할지 정하는 단위로 연속(사이클)·주기·이벤트·하드웨어 인터럽트 태스크가 있습니다. 우선순위가 높은 태스크가 낮은 태스크를 중간에 멈추고 실행되므로, 두 태스크가 같은 변수를 쓰면 값이 계산 도중 바뀔 수 있습니다. |
| OB / Siemens OB | Siemens에서 태스크 역할을 하는 블록입니다. OB 1은 사이클 태스크이고, 최대 사이클 타임을 넘으면 시간 오류 OB(OB 80)가 호출되며 OB 80이 없으면 CPU가 STOP합니다. |
| 폴트 루틴 / Fault routine | 오류가 났을 때 실행되는 처리 루틴입니다. Rockwell Logix는 태스크 워치독을 넘으면 실행 중이던 프로그램의 폴트 루틴을 실행합니다. |
| 직접 I/O 접근 / Direct I/O access | 프로세스 이미지를 거치지 않고 단자를 즉시 읽고 쓰는 방법입니다. Siemens는 주소나 태그 뒤에 `:P`를 붙이며, 같은 스캔 안에서 값이 바뀌어 이미지 일관성이 깨지므로 꼭 필요한 곳에만 씁니다. |
| RUN·STOP / Operating mode | 프로그램을 실행하는 상태와 멈춘 상태입니다. PLC가 멈출 때 출력이 모두 OFF인지, 마지막 값을 유지하는지는 출력 모듈 설정에 따라 다르므로 시운전 때 확인합니다. |
| 핸드셰이크 / Handshake | HMI가 켠 비트를 PLC가 처리한 뒤 직접 리셋하는 방식입니다. HMI가 비트를 켰다가 곧바로 끄면 그 사이 스캔이 지나지 않아 버튼이 무시되는 문제를 막습니다. |

관련 문서: [스캔 사이클과 응답 시간](../basics/scan-cycle.md), [IEC 61131-3 개요](../programming/iec-61131-3.md)

## 입출력과 결선

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 입력 타입 / IEC 61131-2 Type 1·2·3 | IEC 61131-2가 24V DC 디지털 입력을 전압·전류 특성으로 나눈 분류입니다. Type 1은 기계 접점·3선식 센서, Type 2는 누설 전류가 큰 2선식 센서용이고, Type 3은 발열이 적어 Type 1·2 용도로도 쓸 수 있습니다. |
| 싱크·소스 / Sink, Source | 전류가 흘러 들어가는 쪽과 흘러 나오는 쪽입니다. 같은 "싱크 입력"이 입력 단자 기준(COM → 0V, PNP 센서)과 Mitsubishi 등 센서 출력 기준(COM → +24V, NPN 센서)에서 정반대 결선을 뜻하므로 용어보다 회로도로 판단합니다. |
| 공통 단자·공통 그룹 / Common, COM·S/S | 여러 입출력 점이 공유하는 단자와 그 단자를 공유하는 묶음입니다. 한 그룹에는 같은 전원·같은 극성만 쓰고, 점당 한계와 별도로 COM당 합계 전류 한계를 지킵니다. |
| NPN·PNP 센서 / NPN, PNP output | NPN은 출력을 0V로 끌어내리는 싱크형, PNP는 +24V를 내보내는 소스형입니다. 출력선이 0V에 닿는 고장에서 PNP는 OFF로, NPN은 ON으로 읽히며, 배선 색만으로는 둘을 구분할 수 없습니다. |
| 2선식·3선식 센서 / 2-wire, 3-wire sensor | 3선식은 전원 2가닥과 출력 1가닥을 쓰며 누설 전류가 거의 없습니다. 2선식은 OFF에도 누설 전류가 흘러 입력의 OFF 전류 한계보다 크면 센서가 꺼져 있어도 ON으로 읽힙니다. |
| 릴레이 출력 / Relay output | 접점으로 부하를 개폐하는 출력으로 AC·DC 부하 모두 쓸 수 있습니다. 느리고 접점 마모로 개폐 횟수가 제한되므로 펄스·PWM처럼 잦은 개폐에는 트랜지스터 출력을 씁니다. |
| 트랜지스터 출력 / Transistor output | 반도체로 DC 부하를 빠르게 개폐하는 출력입니다. 싱크(NPN)형과 소스(PNP)형이 있어 부하를 +24V 쪽에 둘지 0V 쪽에 둘지가 다릅니다. |
| 트라이액·SSR 출력 / Triac, Solid State Relay | AC 부하를 반도체로 개폐하는 출력입니다. OFF 누설 전류가 있어 작은 부하는 꺼져도 램프가 희미하게 켜질 수 있습니다. |
| 전자 접촉기 / Magnetic contactor, MC | 큰 모터·히터 전원을 개폐하는 장치로, PLC 출력이 직접 구동하기 어려운 부하에 씁니다. 코일은 유도성 부하라서 서지 보호가 필요합니다. |
| 서지 보호 / Surge suppression | 코일 전류를 끊을 때 생기는 역기전력을 억제하는 방법입니다. DC 부하에는 플라이백 다이오드, AC 부하에는 배리스터(MOV)나 RC 스너버가 효과적이며 부하 바로 옆에 답니다. |
| a접점·b접점·c접점 / Normally Open, Normally Closed, Changeover | a접점(NO)은 평상시 열리고 조작 시 닫히며, b접점(NC)은 그 반대이고, c접점은 둘을 함께 가진 전환 접점입니다. b접점으로 배선한 정지 버튼은 평상시 입력이 1이므로 래더에서는 a접점 명령으로 읽습니다. |
| 페일세이프 / Fail-safe | 고장이 안전한 쪽으로 드러나게 하는 설계입니다. 정지·비상·리밋 신호를 b접점으로 배선하면 선이 끊어졌을 때 입력이 OFF가 되어 정지로 판단됩니다. |
| 실드 케이블·접지 / Shielded cable, Grounding | 아날로그·통신·엔코더 선의 노이즈를 줄이는 차폐선과 그 접지입니다. 한쪽 끝 접지가 흔하지만 양쪽 접지와 등전위 본딩을 쓰는 곳도 있어 제조사 설치 지침을 따릅니다. |
| 잠금·표지 / Lockout-Tagout, LOTO | 전원을 차단하고 잠금장치와 표지를 다는 작업 절차입니다. 결선 작업 전, 그리고 STO로 멈춘 드라이브에 전기 작업을 할 때도 합니다. |

## 아날로그 신호

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 4–20 mA 전류 신호 / Current loop | 4 mA를 0%, 20 mA를 100%로 쓰는 아날로그 신호입니다. 배선 저항·노이즈에 강하고 단선을 감지할 수 있습니다. |
| 라이브 제로 / Live zero | 0%를 0 mA가 아니라 4 mA로 두는 방식입니다. 0 mA를 단선이나 전원 이상으로 판단할 수 있으며, 0–20 mA 신호는 0 mA와 단선을 구별하지 못합니다. |
| NE 43 / NAMUR NE 43 | 트랜스미터 고장 신호에 대한 권고로 3.8–20.5 mA를 측정값, 3.6 mA 이하와 21 mA 이상을 고장으로 봅니다. PLC에서는 고장 범위를 측정값으로 쓰지 않고 알람으로 처리하며, 실제 고장 출력값은 트랜스미터 설정을 확인합니다. |
| 2선식·4선식 트랜스미터 / Loop-powered, 4-wire transmitter | 2선식은 신호선 2가닥으로 전원과 신호를 함께 보내고, 4선식은 전원선을 따로 두고 전류를 능동 출력합니다. 아날로그 입력 카드가 전원 공급형인지 외부 전원형인지 맞추지 않으면 전류가 흐르지 않거나 입력 회로가 손상됩니다. |
| 루프 전압 예산 / Loop voltage budget | 전원 전압에서 트랜스미터 최소 동작 전압을 뺀 나머지로 허용 루프 저항을 계산하는 것입니다. 아날로그 입력 저항, 배선 저항, 표시계·배리어 저항의 합이 그 안에 들어와야 합니다. |
| 0–10 V 전압 신호 / Voltage signal | 결선이 간단한 아날로그 신호입니다. 긴 배선에서 전압 강하·노이즈에 약하고 단선을 0%로 오인할 수 있습니다. |
