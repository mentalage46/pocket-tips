# 안전·보안 용어

[전체 용어 색인](./README.md)

> 용어 이해를 돕는 정리입니다. 실제 설비의 안전 설계와 판정은 표준 원문, 국내 법령, 자격을 갖춘 안전 담당자의 검토를 따릅니다.

## 기능 안전

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 기능 안전 / Functional safety | 제어 시스템이 올바르게 동작해서 위험을 줄이는 것을 다루는 분야입니다. 가드·비상정지·라이트 커튼 신호를 받아 기계를 멈추는 회로나 프로그램이 여기에 속합니다. |
| 리스크 평가 / Risk assessment, ISO 12100 | 기계의 제한 사항 결정, 위험원 식별, 리스크 추정·평가로 이어지는 절차입니다. 본질적 안전 설계 → 방호 조치 → 사용 정보 순서로 위험을 줄이며, 설계로 없앨 수 있는 위험을 가드나 경고문으로 때우지 않습니다. |
| 안전 기능 / Safety function | 고장 나면 리스크가 즉시 커지는 기능으로 가드가 열리면 모터 정지, 비상정지, 안전 속도 제한 등이 있습니다. 센서 → 로직 → 출력 체인 전체로 봅니다. |
| SRP/CS / Safety-Related Parts of Control Systems | 안전 기능 하나를 입력(센서)부터 출력(동력 차단 소자)까지 수행하는 제어 시스템 부분입니다. ISO 13849-1:2023은 이를 입력·로직·출력 서브시스템과 명확히 구분합니다. |
| PL·PLr / Performance Level, required PL | ISO 13849-1의 안전 기능 등급(a–e)과, 리스크 평가로 정한 그 안전 기능의 요구 등급입니다. 안전 릴레이 하나가 PL e 인증이어도 센서·출력이 약하면 체인 전체의 PL은 낮아집니다. |
| 위험 그래프 / Risk graph, S·F·P | 상해 심각도(S), 노출 빈도·시간(F), 회피 가능성(P)으로 PLr을 정하는 부속서 A의 도표입니다. 2023판은 P를 다섯 요소로 판단하고 위험 사건 발생 확률을 P에서 따로 떼어 냈습니다. |
| 카테고리 / Category B, 1–4 | ISO 13849-1의 SRP/CS 구조 분류로, 카테고리 3·4는 이중 채널입니다. IEC 60204-1의 정지 카테고리 0·1·2와는 전혀 다른 개념입니다. |
| MTTFD / Mean Time To dangerous Failure | 채널당 평균 위험 고장 시간입니다. 낮음·중간·높음 등급으로 나누어 달성 PL 계산에 씁니다. |
| DCavg / average Diagnostic Coverage | 평균 진단 범위로, 없음(60% 미만)부터 높음(99% 이상)까지 등급을 나눕니다. |
| CCF / Common Cause Failure | 공통 원인 고장입니다. 카테고리 2·3·4는 부속서 F 점수표에서 65점 이상을 받아야 합니다. |
| PFH / average frequency of a dangerous failure per hour | 시간당 평균 위험 고장 빈도로 PL마다 범위가 정해져 있습니다. 2023판에서 PFHD를 IEC 표준과 같은 PFH로 이름만 바꿨고 기술적 변화는 없습니다. |
| SIL / Safety Integrity Level | IEC 61508 계열의 안전 무결성 등급입니다. PL과 대응 관계는 있지만 환산 규칙이 아니고, 기계 분야는 SIL 1–3만 다룹니다. |
| IEC 61508·IEC 62061·IEC 61511 | 모든 E/E/PE 안전 시스템의 기본 표준과, 그 기계 부문 적용(IEC 62061), 공정 산업 안전 계장 시스템(SIS) 적용(IEC 61511)입니다. ISO 13849-1은 요구가 연 1회보다 잦은 안전 기능만 다루고 저빈도 요구는 IEC 61508 계열로 안내합니다. |
| SRS / Safety Requirements Specification | 안전 기능마다 트리거 이벤트, 안전 상태, PLr, 허용 응답 시간, 재기동 조건 등을 적은 명세입니다. ISO 13849-1:2023은 설계 전에 작성하고 검토하도록 요구합니다. |
| 확인 / Validation | 안전 기능이 요구대로 동작하는지 실제로 시험해 확인하는 활동입니다. 배선 단선·단락·접점 용착 같은 결함 주입에 대한 반응까지 시험하고 기록합니다. |
| SISTEMA | 독일 IFA가 무료로 배포하는 ISO 13849-1 계산 도구입니다. 3.x는 2023판, 2.x는 2015판 기준이며 2.x 프로젝트를 3.0에서 열면 파일 형식이 바뀌어 되돌릴 수 없습니다. |
| 안전 서명 / Safety signature | 안전 프로그램 상태를 식별하는 CRC 값으로 Rockwell GuardLogix의 safety signature, Siemens의 collective F-signature가 예입니다. 서명이 바뀌면 해당 안전 기능을 다시 검증·승인해야 합니다. |
| EU 기계 규정 / Regulation (EU) 2023/1230 | 기계 지침 2006/42/EC를 대체해 회원국에 직접 적용되는 규정으로 2027-01-20부터 적용합니다. 손상(corruption)에 대한 보호, 안전 소프트웨어 버전 추적 로그 같은 사이버 보안 성격의 요구가 들어 있습니다. |

관련 문서: [기능 안전 기초](../safety/functional-safety.md), [PLC 구조와 형태](../basics/plc-architecture.md)

## 비상정지와 인터록

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 비상정지 / Emergency stop, ISO 13850 | 실제 또는 임박한 위험을 피하기 위한 보완 방호 조치입니다. 모든 운전 모드에서 다른 기능보다 우선하지만 가드·인터록·안전 기능을 대신하지 않으며, PLC 일반 입력만으로 처리하지 않고 안전 회로로 구현합니다. |
| 정지 카테고리 / Stop category 0·1·2 | IEC 60204-1의 정지 방식으로 0은 즉시 전원 차단, 1은 제어 정지 후 전원 차단, 2는 제어 정지 후 전원 유지입니다. 비상정지는 0 또는 1만 쓰며, ISO 13849-1의 카테고리와는 다른 개념입니다. |
| 래칭·직접 개로 / Latching, Direct opening action | 비상정지 장치가 눌린 상태로 기계적으로 잠겨 리셋할 때까지 정지 명령을 유지하는 것과, 이를 위해 전기식 장치가 쓰는 접점 동작입니다. |
| 리셋·재기동 / Reset, Restart | 리셋은 재기동을 허용할 뿐이고, 재기동은 별도 시작 조작으로 합니다. 비상정지 해제나 리셋만으로 기계가 다시 움직이면 안 됩니다. |
| 안전 릴레이 / Safety relay | 비상정지·도어 스위치 신호를 감시하고 출력 접촉기를 제어하는 전용 모듈입니다. 단순하고 검증이 쉬워 안전 기능이 몇 개뿐인 기계에 맞고, 많거나 존별 정지가 필요하면 안전 PLC를 검토합니다. |
| 듀얼 채널·교차 감시 / Dual channel, Cross monitoring | 입력을 2채널로 받아 한 채널이 단선·용착돼도 다른 채널로 정지하고, 두 채널이 함께 바뀌는지와 채널 간 단락을 검사해 불일치하면 재기동을 막는 구성입니다. |
| EDM / External Device Monitoring | 출력 접촉기의 강제 가이드(미러) 보조 NC 접점을 리셋 회로에 넣어, 접촉기가 용착돼 떨어지지 않았으면 리셋되지 않게 하는 피드백입니다. 보조 접점이 주접점과 기계적으로 연동되는 미러 접점이어야 의미가 있습니다. |
| 수동·자동 리셋 / Manual, Automatic reset | 수동 리셋은 사람이 위험 구역 밖에서 상황을 확인하고 누르며, 버튼을 눌러 고정하는 오용을 막기 위해 신호 에지를 감시합니다. 자동 리셋은 사람이 위험 구역에 들어갈 수 없는 구조에서만 씁니다. |
| 인터록 장치 / Interlocking device, ISO 14119 | 가드가 열리면 위험한 동작을 멈추고 닫힐 때까지 시작하지 못하게 하는 장치로, 작동 방식에 따라 타입 1–5로 나눕니다. 코드 수준이 높을수록 예비 액추에이터로 우회하기 어렵고, 2024판에서 트랩 키 시스템이 타입 5로 들어갔습니다. |
| 무력화 / Defeat | 인터록·안전 기능을 우회하는 것입니다. 셋업·청소 때마다 정지·재기동이 오래 걸리면 결국 우회되므로, 우회하고 싶어지는 동기부터 설계로 줄입니다. |
| 가드 잠금 / Guard locking | 정지 시간이 접근 시간보다 길 때 기계가 멈출 때까지 가드를 잠가 두는 기능입니다. 가드 위치를 감시하는 인터록과는 별개의 안전 기능이라 각각 PLr을 정합니다. |
| 라이트 커튼 / Light curtain, AOPD | 빛이 가려지면 정지 신호를 내는 전자 감응 보호 장치(ESPE)입니다. IEC 61496 타입도 함께 보는데 라이트 커튼은 타입 2와 4만 정의되어 있어 PLr d가 필요하면 보통 타입 4를 씁니다. |
| 안전 거리 / Separation distance, ISO 13855 | 정지 신호 뒤 기계가 멈출 때까지 사람이 위험점에 닿지 않도록 두는 거리입니다. 2024판은 식이 S = K × T + DDS + Z로 바뀌었으므로 예전 자료의 공식을 그대로 쓰지 않고, 전체 정지 시간 T는 실측합니다. |
| 뮤팅 / Muting | 물체가 지나갈 때 라이트 커튼을 일시 무효화하는 기능입니다. 센서 배치·순서·시간으로 사람과 물체를 구분해야 하며 뮤팅 로직도 안전 기능입니다. |
| STO / Safe Torque Off | 드라이브가 모터에 토크를 만드는 에너지를 공급하지 않게 하는 안전 하위 기능으로 정지 카테고리 0에 해당하며, 안전 출력으로 끊어야 합니다. 전기적 절연이 아니므로 전기 작업 전에는 주 전원 차단과 LOTO를 하고, 수직축은 안전 브레이크 제어(SBC)·기계 브레이크와 함께 씁니다. |
| SS1·SLS / Safe Stop 1, Safely-Limited Speed | 드라이브 안전 기능으로 SS1은 감속 후 STO(정지 카테고리 1), SLS는 안전 제한 속도입니다. |
| 블랙 채널 / Black channel | 일반 네트워크를 믿지 않고 안전 계층이 일련번호·타임아웃·CRC·송수신자 식별로 손실·지연·위조를 검출하는 안전 통신 방식입니다. 통신 watchdog 시간이 안전 거리 계산의 T에 더해집니다. |
| PROFIsafe·CIP Safety·FSoE | 각각 PROFINET(PROFIBUS), EtherNet/IP(DeviceNet), EtherCAT 위에서 쓰는 대표 안전 프로토콜입니다. FSoE는 Safety over EtherCAT의 약자입니다. |

## OT 보안

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| OT / Operational Technology | PLC·HMI·SCADA·드라이브처럼 물리 공정을 제어하는 시스템입니다. IT와 달리 안전·가용성을 기밀성보다 먼저 두며, 계정 잠금처럼 보안 조치가 비상 운전을 막지 않게 설계합니다. |
| IEC 62443 / IACS security | 산업 자동화·제어 시스템(IACS) 보안 표준 시리즈입니다. 자산 소유자, 시스템 통합자, 제품 공급자, 서비스 공급자의 요구사항을 나눠 정합니다. |
| 존·콘딧 / Zone, Conduit | 보안 요구가 비슷한 자산의 묶음과, 존 사이의 통제된 통신 경로입니다. IIoT·클라우드 연동으로 레벨 경계가 흐려지면서 레벨보다 존·콘딧으로 설계하는 경우가 늘고 있습니다. |
| 보안 레벨 / Security Level, SL 1–4 | 막아야 할 위협 수준에 따른 등급으로 SL 1은 우발적 오용, SL 4는 많은 자원을 가진 국가 수준 공격입니다. |
| SL-T·SL-C·SL-A | 목표 보안 레벨, 제품·시스템이 낼 수 있는 능력, 실제 달성 수준입니다. 장비의 "IEC 62443-4-2 SL 2 인증"은 SL-C이며, 설치 후 시스템이 그 수준을 달성하는지는 별개입니다. |
| 기본 요구사항 / Foundational Requirements, FR | 식별·인증 제어, 사용 제어, 시스템 무결성, 데이터 기밀성, 데이터 흐름 제한, 이벤트 적시 대응, 자원 가용성의 7가지 요구 분류입니다. |
| IT/OT DMZ | IT와 OT 사이에 두는 완충 네트워크(Purdue 레벨 3.5)입니다. 두 망이 직접 통신하지 않게 하고, 히스토리안 복제본·패치 서버·원격 접속용 점프 호스트를 둡니다. |
| PLC 운전 모드 키 / Mode key switch, RUN·PROG·REMOTE | PLC의 물리 운전 모드 스위치입니다. 평소에는 RUN에 두고 키를 관리하며, 프로그램을 바꿀 때만 PROG·REMOTE로 돌립니다. |
| 보호 레벨 / Protection level | 쓰기 보호, 읽기·쓰기 보호, know-how 보호 같은 PLC 접근 보호 설정입니다. 기본 비밀번호를 바꾸고 계정을 사람별로 나눕니다. |
| 정상본 / Gold copy | 검증된 PLC 프로그램·설정·HMI 프로젝트의 오프라인 백업입니다. 실행 중 로직과 주기적으로 비교해 변경을 감지하고, 공격자가 비밀번호를 바꿔도 복구할 수 있게 복원을 연습합니다. |
| 인터넷 노출 / Internet exposure | PLC·HMI·RTU가 공인 IP에서 보이는 상태입니다. 2023년 이후 공격 대부분이 인터넷 노출과 기본·약한 비밀번호에서 시작했으므로 102·502·44818·2222 같은 OT 포트가 밖에서 보이지 않는지 점검합니다. |
| 수동 모니터링 / Passive monitoring | 트래픽을 듣기만 하는 감시 방식입니다. IT용 능동 스캐너는 구형 장치를 멈추게 할 수 있어 OT에서는 수동 모니터링을 기본으로 하고 능동 점검은 계획 정지 때 합니다. |
| ATT&CK for ICS | MITRE의 ICS 공격 기법 지식 베이스입니다. Inhibit Response Function(안전·보호 기능 방해), Impair Process Control, Impact가 OT 고유 전술입니다. |
| CRA / Cyber Resilience Act | 디지털 요소가 있는 제품의 제조사에 보안 요구를 부과하는 EU 규정으로, 네트워크에 연결되는 PLC·HMI·엔지니어링 소프트웨어도 대상이 될 수 있습니다. 보고 의무는 2026-09-11, 전면 적용은 2027-12-11부터입니다. |
| NIS2 | 필수·중요 기관에 사이버 보안 위험 관리와 사고 보고를 요구하는 EU 지침입니다. 주요 제품 제조업도 적용 분야에 들어가므로 해당 국가의 전환법을 확인합니다. |
