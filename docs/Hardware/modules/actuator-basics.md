# 출력 장치 기초

모터·서보·릴레이는 전기 신호를 움직임이나 접점 동작으로 바꿉니다. GPIO는 제어 신호를 전달하고, 부하 전류는 정격에 맞는 전원과 드라이버가 담당하도록 구성합니다.

먼저 알면 좋은 개념: [기동·스톨 전류와 유도성 부하](../glossary/electrical.md#전류와-구동), [펄스 폭과 듀티비](../glossary/signals.md#시간과-파형), [전원과 노이즈](../background/power-and-noise.md)

## 장치별 제어 방식

| 장치 | 일반적인 제어 | 필요한 확인 |
| --- | --- | --- |
| 브러시 DC 모터 | 드라이버에 PWM·방향 입력 | 정격 전압, 기동·스톨 전류, 발열 |
| 위치 제어형 RC 서보 | 주기적인 제어 펄스 | 펄스 폭, 공급 전원, 이동 범위, 스톨 전류 |
| 연속 회전 RC 서보 | 제어 펄스로 방향·속도 지정 | 중립값, 속도 범위; 각도 제어와 구별 |
| 스테퍼 모터 | 전류 제어 드라이버, STEP/DIR 등 | 상 전류, 전류 제한 설정, 가감속, 탈조 |
| 릴레이 | 코일 구동 또는 모듈의 제어 입력 | 코일 전압, 접점의 AC/DC 정격, 부하 종류 |

## 모터 전원과 드라이버

기동 시나 축이 멈춘 상태의 전류는 무부하 전류보다 훨씬 클 수 있습니다. 드라이버의 광고상 최대 전류보다 실제 냉각 조건에서의 연속 전류와 피크 허용 시간을 확인합니다.

```text
MCU GPIO/PWM ───── 드라이버 제어 입력
MCU GND ──┬─────── 드라이버 GND
외부 전원 - ┘
외부 전원 + ────── 드라이버 모터 전원
드라이버 출력 ───── 모터
```

이는 비절연 드라이버의 개념도입니다. 드라이버 논리 전원과 모터 전원이 분리되어 있다면 각각의 요구 조건을 따릅니다. 보드의 작은 레귤레이터로 모터 전류를 공급하지 않습니다.

## 유도성 부하와 보호

릴레이 코일이나 모터의 전류를 갑자기 끊으면 큰 전압이 발생할 수 있습니다. **유도성 부하**는 코일처럼 자기장에 에너지를 저장하는 부하이며, **플라이백 다이오드**는 스위치를 끈 뒤에도 전류가 순환할 경로를 제공해 과도 전압을 제한합니다.

- 단방향 로우사이드 스위치로 DC 코일을 구동할 때는 코일 양단에 플라이백 다이오드를 두는 구성이 흔합니다.
- 이 구성에서 다이오드 **캐소드는 전원 +**, **애노드는 스위치 쪽 코일 단자**에 연결해 정상 구동 중에는 역바이어스가 되게 합니다.
- 다이오드의 전류·역전압·회복 특성은 부하와 스위칭 조건에 맞춥니다.
- H-브리지로 양방향 구동하는 모터에는 위 단일 다이오드 구성을 그대로 적용하지 않습니다. 드라이버가 요구하는 전류 순환 경로와 보호 회로를 사용합니다.
- 일부 드라이버·릴레이 모듈에는 보호 소자가 내장되어 있으므로 회로도를 확인합니다.

## PWM과 서보 펄스의 차이

DC 모터 드라이버는 흔히 PWM의 듀티비로 출력을 조절합니다. 위치 제어형 RC 서보는 보통 **펄스 폭**으로 목표 위치를 전달합니다.

약 20ms 주기와 1~2ms 펄스 폭을 사용하는 서보가 흔하지만 제품마다 다르며, 해당 범위가 항상 0~180도를 뜻하지도 않습니다. 데이터시트 범위 안에서 기구물과 간섭하지 않는 좁은 구간부터 확인합니다.

## 최소 DC 모터 제어 흐름

아래는 PWM과 enable을 제공하는 드라이버의 의사코드입니다. 핀의 active-high/low와 정지 방식은 실제 드라이버의 진리표를 따릅니다.

```text
전원 투입·리셋 중 외부 저항으로 enable 비활성 유지
드라이버 설정과 전원 상태 확인
PWM을 정지에 해당하는 값으로 설정
방향 설정
드라이버 활성화
목표 출력까지 점진적으로 PWM 조정

정지 요청 또는 오류:
    드라이버 사양에 따른 정지 출력 적용
    필요하면 enable 비활성화
    오류 상태 기록
```

회전 방향을 바꿀 때는 출력을 낮추고 정지 조건을 확인합니다. 감속·브레이크·역전 과정에서 전류와 회생 에너지로 전원 전압이 상승할 수 있습니다. 코스트(관성 회전)와 브레이크(제동)는 다르며, PWM 0%가 어떤 동작을 만드는지도 드라이버에 따라 다릅니다.

## 실습 확인 항목

- 전원·드라이버·배선이 기동 전류를 감당하는가?
- 리셋이나 통신 단절 때 의도하지 않게 동작하지 않는가?
- 손이나 배선이 회전체에 닿지 않도록 고정했는가?
- 모터를 장시간 스톨 상태로 두지 않는가?
- 릴레이 실습은 저전압 DC 부하로 진행하는가? 접점에 상용 전원을 연결하는 작업은 이 입문 실습 범위에 포함하지 않습니다.
