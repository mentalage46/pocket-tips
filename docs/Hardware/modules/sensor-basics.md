# 센서 기초

센서 제어는 전원 공급, 초기화, 측정 완료 확인, 값 변환, 오류 처리의 흐름으로 구성됩니다.

먼저 알면 좋은 개념: [해상도·정확도·오프셋·게인](../glossary/signals.md#변환과-측정), [MSB/LSB·2의 보수·raw](../glossary/firmware.md#데이터와-레지스터), [샘플링과 측정 오차](../background/sampling-and-error.md)

## 출력 방식에 따른 구분

| 센서 출력 | 읽는 방법 | 확인할 내용 |
| --- | --- | --- |
| 아날로그 전압 | ADC로 읽기 | 출력 범위, 기준 전압, 전달 함수 |
| 디지털 상태 | GPIO로 읽기 | active-high/low, 풀업, 출력 방식 |
| 펄스·주파수 | 카운터·타이머로 측정 | 펄스 폭, 최대 주파수, 측정 창 |
| 디지털 데이터 | I2C·SPI·UART로 읽기 | 주소·모드, 초기화, 데이터 형식 |

## 연결 전에 기록할 정보

- 정확한 센서와 모듈의 모델명, 보드 버전
- 공급 전압, 소비 전류, 신호 핀의 논리 전압
- 핀맵과 풀업·레벨 시프터 유무
- 측정 범위, 정확도, 분해능, 최대 측정 속도
- 전원 투입 후 준비 시간과 1회 변환 시간
- 데이터시트 링크·리비전, 모듈 회로도

| 보드 | 센서 모듈 | 확인 |
| --- | --- | --- |
| 호환 전원 | VCC/VIN | 칩 전압과 모듈 입력 전압 구별 |
| GND | GND | 공통 기준 |
| SDA | SDA | 풀업 유무와 전압 |

## 최소 측정 흐름

아래는 식별 레지스터와 단발 측정 기능이 있는 **가상의 센서**를 설명하는 의사코드입니다. 실제 장치의 주소·레지스터·명령을 지정한 실행 예제는 아닙니다.

```text
전원 안정화와 센서 준비 시간 대기
타임아웃을 설정해 통신 초기화
식별값 읽기 → 예상 모델과 다르면 오류
측정 범위와 출력 속도 설정

주기마다:
    측정 시작 명령 전송 → 실패하면 오류 처리
    완료 상태를 제한 시간 안에서 확인 → 초과하면 오류 처리
    데이터 읽기 → 전송 결과와 제공되는 CRC 확인
    바이트 순서, 비트 정렬, 부호를 적용해 raw 해석
    데이터시트의 변환식으로 단위 변환
    유효 범위 확인
    값, 단위, 측정 시각, 유효 상태 저장
```

연속 측정 센서는 매번 시작 명령을 보내지 않을 수 있습니다. 같은 측정값을 반복해서 읽는지 구별하려면 data-ready 비트나 데이터 갱신 주기를 확인합니다. 여러 바이트가 같은 측정 시점의 값인지 보장하는 읽기 절차도 따릅니다.

## 단위 변환 예시

가상의 온도 센서가 MSB 우선의 16비트 2의 보수 값과 `0.01°C/LSB` 스케일을 사용한다고 가정합니다. 여기서 **MSB 우선**은 상위 바이트를 먼저 받는다는 뜻이고, **2의 보수**는 음수도 나타내는 정수 표현 방식입니다. **°C/LSB**는 코드가 한 단계 변할 때의 온도 변화량입니다.

```text
수신: 0x09, 0xC4
raw = 0x09C4 = 2500
온도 = 2500 × 0.01 = 25.00°C

수신: 0xFF, 0x9C
부호 없는 값 = 65436
부호 있는 값 = 65436 - 65536 = -100
온도 = -100 × 0.01 = -1.00°C
```

이 스케일을 다른 센서에 적용하면 안 됩니다. 센서마다 오프셋, 보정 계수, 비선형 변환이 다릅니다.

## 보정과 필터링

- **오프셋 보정**: 기준 장비와 비교해 일정한 치우침을 조정합니다.
- **게인 보정**: 두 점 이상을 기준으로 비례 오차를 조정합니다.
- **이동 평균**: 최근 N개의 유효 샘플을 평균합니다. 노이즈를 줄이지만 변화에 늦게 반응합니다.
- **지수 이동 평균**: `filtered = α × sample + (1 - α) × previous`, `0 < α <= 1`. 첫 유효 샘플로 초기화하고, α가 작을수록 평활화와 지연이 커집니다.

필터링은 단위 변환 오류나 전원 문제를 해결하지 않습니다. 오류 샘플을 0으로 넣어 평균을 왜곡하지 않고, 이전 값의 시각과 유효 여부를 유지합니다.

## 흔한 문제

| 증상 | 확인할 원인 |
| --- | --- |
| 항상 같은 값 | 측정 시작 누락, 갱신 전 읽기, 잘못된 레지스터 |
| 음수가 큰 양수로 표시 | 부호 해석 오류 |
| 값이 일정 배수로 틀림 | 스케일·단위·비트 정렬·측정 범위 설정 |
| 드문 급격한 튐 | 전원 노이즈, 통신 오류, 측정 바이트 일관성 |
| 가끔 응답 없음 | 준비 시간, 배선, 풀업, 주소 충돌, 타임아웃 |
