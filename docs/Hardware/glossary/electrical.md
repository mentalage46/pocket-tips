# 전기·전자 용어

짧은 정의를 먼저 읽고, 원리가 궁금하면 각 절의 관련 문서를 따라갑니다. [전체 용어 색인](./README.md)

## 전압과 전원

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 전위·전위차 / Potential | 전위는 기준점에 대한 전압 수준을 나타냅니다. 두 지점의 전위 차이가 전압이며, 단위는 볼트(V)입니다. |
| 접지 / Ground, GND | 회로에서 전압을 비교하는 기준점입니다. 반드시 대지나 건물의 보호 접지에 연결된다는 뜻은 아닙니다. |
| 부하 / Load | 전원이나 신호 출력에 연결되어 전류를 받는 회로·부품입니다. 모터뿐 아니라 GPIO 입력도 출력 쪽에서 보면 부하입니다. |
| 정격 / Rating | 제조사가 명시한 사용 조건이나 한계입니다. 전압·전류·전력·온도 등 무엇의 정격인지 함께 읽습니다. |
| 절대 최대 정격 / Absolute Maximum Ratings | 넘으면 손상될 수 있는 한계 조건입니다. 그 이하라 해도 정상 동작이 보장되는 것은 아닙니다. |
| 레귤레이터 / Regulator | 입력 전원으로부터 일정한 출력 전압 등을 유지하는 회로입니다. 허용 입력, 출력 전류와 발열에 제한이 있습니다. |
| 전압 강하 / Voltage drop | 배선·부품을 지나면서 생기는 전압 차이입니다. 부하 전류가 커지면 배선 저항에 의한 강하도 커집니다. |
| 리턴 경로 / Return path | 부하로 간 전류가 전원으로 돌아가는 경로입니다. 전류는 신호선 하나만으로 흐르지 않고 닫힌 경로가 필요합니다. |
| 역급전 / Backfeeding | 의도한 전원 입력 외의 경로로 전원이 들어오는 현상입니다. 꺼진 칩의 신호 핀을 통해 전류가 들어오는 경우도 있습니다. |
| 단락·도통 / Short circuit, Continuity | 단락은 의도하지 않은 낮은 저항의 연결이고, 도통은 전류가 통하는 연결 상태입니다. 도통 알림이 항상 배선 오류를 뜻하지는 않습니다. |

## 저항과 정전용량

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 임피던스 / Impedance, Z | 전압 변화에 대해 전류가 얼마나, 어떤 위상으로 흐르는지 나타내는 양입니다. 저항과 커패시터 등의 영향을 포함하며 주파수에 따라 달라질 수 있습니다. 단위는 옴(Ω)입니다. |
| 정전용량 / Capacitance, C | 전압 변화에 따라 저장되는 전하량의 정도입니다. 단위는 패럿(F)이며, 커패시터뿐 아니라 배선과 입력 핀에도 존재합니다. |
| 기생 정전용량 / Parasitic capacitance | 의도적으로 커패시터를 달지 않아도 도체 사이에 생기는 정전용량입니다. 통신선의 신호 변화 속도에 영향을 줍니다. |
| 버스 정전용량 / Bus capacitance | 공유 신호선에 연결된 배선·핀 등의 정전용량을 합쳐 본 값입니다. 장치 수와 배선에 따라 달라집니다. |
| 시정수 / Time constant, τ | 변화가 진행되는 시간 규모입니다. 단순 RC 회로에서는 `τ = R × C`이고, 충전 시 한 시정수 뒤 전체 변화량의 약 63%에 도달합니다. |
| 소스 저항 / Source resistance | 신호를 공급하는 회로를 바라봤을 때 보이는 저항입니다. ADC 입력의 충전 시간이나 부하에 따른 전압 변화에 영향을 줍니다. |
| 등가 직렬 저항 / Equivalent Series Resistance, ESR | 실제 커패시터 등의 손실을 직렬 저항으로 표현한 값입니다. 발열과 전압 변동에 영향을 줍니다. |
| DC 바이어스 / DC bias | 부품에 지속적으로 걸어 둔 직류 전압·전류 조건입니다. 일부 세라믹 커패시터는 걸린 DC 전압이 커지면 실제 정전용량이 줄어듭니다. |
| 디커플링·벌크 커패시터 / Decoupling, Bulk capacitor | 디커플링은 전원 변동이 회로에 전달되는 것을 줄이는 역할입니다. 벌크 커패시터는 상대적으로 큰 용량으로 전하를 보충합니다. 실제 효과는 용량·특성·배치에 함께 좌우됩니다. |

관련 문서: [정전용량과 신호 타이밍](../background/capacitance-and-timing.md), [기본 부품](../basics/components.md)

## 전류와 구동

| 용어 / 영문·약어 | 뜻과 읽을 때 주의할 점 |
| --- | --- |
| 소스·싱크 전류 / Source, Sink current | 소스는 출력 핀에서 외부로 내보내는 전류, 싱크는 외부에서 핀으로 받아들이는 전류입니다. 출력 능력은 둘을 나누어 명시하기도 합니다. |
| 누설 전류 / Leakage current | 차단·고임피던스 상태에서도 작게 흐르는 전류입니다. 저항값이 큰 풀업·풀다운에서는 논리 전압에 영향을 줄 수 있습니다. |
| 기동·스톨 전류 / Startup, Stall current | 기동 전류는 모터가 출발할 때, 스톨 전류는 축이 회전하지 못하는 상태에서 흐르는 전류입니다. 크기는 모터 종류와 드라이버의 전류 제한 등에 따라 달라집니다. |
| 유도성 부하 / Inductive load | 코일처럼 자기장에 에너지를 저장하는 부하입니다. 전류가 급격히 바뀌면 큰 전압이 생길 수 있습니다. |
| 플라이백 다이오드 / Flyback diode | 코일의 스위치를 끈 뒤에도 전류가 순환할 경로를 제공해 과도 전압을 제한하는 다이오드입니다. 구동 방식에 맞는 보호 회로가 필요합니다. |
| 순방향·역방향 바이어스 / Forward, Reverse bias | 다이오드에 전압을 거는 방향입니다. 순방향은 주로 전류가 흐르는 방향, 역방향은 주로 차단하는 방향이며 각각 허용 한계가 있습니다. |
| 애노드·캐소드 / Anode, Cathode | 다이오드의 두 단자 이름입니다. 일반적인 순방향 전류는 애노드에서 캐소드로 흐릅니다. |
| 로우사이드 스위칭 / Low-side switching | 부하와 GND 사이에 스위치 소자를 두어 전류를 제어하는 방식입니다. |
| H-브리지 / H-bridge | 부하 양단에 걸리는 전압 방향을 바꿀 수 있는 스위치 회로입니다. DC 모터의 정·역회전에 사용합니다. |
| 문턱 전압·온저항 / VGS(th), RDS(on) | MOSFET의 문턱 전압은 정해진 작은 전류가 흐르기 시작하는 조건이고, 온저항은 켜진 상태의 드레인·소스 사이 저항입니다. 문턱 전압만으로 충분히 켜졌다고 판단하지 않습니다. |
| 탈조 / Missed steps | 스테퍼 모터가 명령한 스텝을 따라가지 못해 실제 위치가 예상 위치와 달라지는 현상입니다. |
| 회생 / Regeneration | 감속하는 모터 등의 기계 에너지가 전기 에너지로 돌아오는 현상입니다. 전원이 이를 흡수하지 못하면 전원 전압이 올라갈 수 있습니다. |
