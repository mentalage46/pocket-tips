# Hardware

전기·전자 기초부터 GPIO, 통신 인터페이스, 센서와 모터 제어까지 정리한 입문 가이드입니다.

특정 보드나 SDK에 종속되지 않는 개념을 다룹니다. 코드 중 `text` 블록은 동작 순서를 설명하는 의사코드이며, 실제 핀 번호·전압·API는 사용하는 보드와 모듈의 문서에 맞춰야 합니다.

## 용어와 배경지식 찾아보기

- [용어집](./glossary/README.md): 한글·영문·약어로 짧은 뜻을 찾습니다.
- [배경지식](./background/README.md): 회로가 그렇게 동작하는 이유를 그림과 계산 예시로 읽습니다.
- 각 문서의 **먼저 알면 좋은 개념**에서 필요한 설명으로 이동할 수 있습니다. 본문의 **용어 풀이**는 읽는 흐름에 필요한 짧은 설명입니다.

처음에는 아래 학습 순서를 따라가고, 모르는 용어가 나올 때 용어집을 참고합니다. 배경지식을 모두 먼저 읽을 필요는 없습니다.

## 추천 실습 순서

처음에는 보드가 지원하는 저전압 DC 전원과 소형 부품으로 실습합니다.

| 단계 | 실습 | 확인할 개념 | 성공 기준 |
| --- | --- | --- | --- |
| 1 | LED와 직렬 저항 연결 | 극성, 전류 제한, GPIO 출력 | 정한 주기로 LED가 켜지고 꺼짐 |
| 2 | 버튼 입력 읽기 | 풀업, active-low, 디바운싱 | 버튼 한 번에 이벤트가 한 번 발생 |
| 3 | PWM으로 LED 밝기 조절 | 주파수, 듀티비 | 듀티비에 따라 밝기가 달라짐 |
| 4 | 가변저항 전압 읽기 | 분압, ADC, 기준 전압 | 회전 방향에 따라 측정값이 연속적으로 변함 |
| 5 | I2C 센서 읽기 | 주소, 초기화, 단위 변환 | 식별값과 측정값을 읽고 오류를 구분 |
| 6 | 드라이버로 DC 모터 제어 | 별도 전원, 공통 GND, 기동 전류 | 안전한 정지 상태에서 시작해 속도를 조절 |

가변저항의 양 끝은 GND와 **ADC 허용 입력 범위 안의 전압**에 연결하고, 가운데 단자를 ADC에 연결합니다. 모터는 GPIO에 직접 연결하지 않고 정격에 맞는 드라이버를 사용합니다.

## 새 모듈 문서 작성 형식

새 센서·디스플레이·통신 모듈을 추가할 때는 `modules/` 아래에 소문자와 하이픈으로 파일을 만듭니다.

1. **용도와 모델**: 부품명, 모듈/보드 버전, 측정하거나 제어하는 대상
2. **전원과 신호 전압**: 공급 전압, 소비·최대 전류, 논리 전압
3. **핀맵과 배선**: 보드 핀 번호 체계, 핀별 연결, 추가 저항·드라이버
4. **통신과 초기화**: 인터페이스, 주소/모드, 준비 시간, 초기 설정
5. **최소 제어 예제**: 보드·SDK 버전, 실행 방법, 예상 결과
6. **오류와 종료 처리**: 타임아웃, 재시도, 정지 상태, 흔한 배선 문제
7. **참고 자료**: 제조사 데이터시트와 모듈 회로도, 확인한 문서 버전

공통 개념은 위 기초 문서에 연결하고, 모듈 문서에는 해당 제품의 조건과 차이를 기록합니다.

## 설명을 추가할 때의 기준

- 한두 문장으로 풀 수 있는 용어는 처음 나오는 본문에 괄호나 인용문으로 설명합니다. HTML 주석처럼 독자에게 보이지 않는 곳에 설명을 숨기지 않습니다.
- 여러 문서에서 반복되는 용어는 `glossary/`의 분야별 파일에 한국어·영문·약어와 짧은 정의를 기록하고, [용어 색인](./glossary/README.md)에도 연결합니다.
- 원리·회로 그림·계산이 필요한 공통 설명은 `background/`에 둡니다. 기존 `basics/`에 충분한 설명이 있으면 그 문서에 연결합니다.
- 주제 문서에는 연결·사용·점검 절차를 남기고, 용어집 → 배경 설명 → 적용 문서로 이동할 수 있게 링크를 둡니다.
- 새 파일은 기존 규칙처럼 소문자와 하이픈으로 이름을 짓고, 용어마다 파일을 만들기보다 관련 개념을 묶습니다.
