# UART

UART는 별도의 클록선 없이 합의한 전송 속도와 프레임 형식으로 데이터를 주고받는 직렬 통신 방식입니다.

먼저 알면 좋은 개념: [UART·TX/RX·baud·패리티](../glossary/communication.md#uart), [프레임과 CRC](../glossary/communication.md#연결과-데이터-단위)

## 기본 연결

```text
장치 A TX ───── 장치 B RX
장치 A RX ───── 장치 B TX
장치 A GND ──── 장치 B GND
```

이 그림은 전압이 호환되는 비절연 논리 레벨 UART의 예입니다. 단방향 통신이면 필요한 송신·수신선만 연결할 수 있습니다. RTS/CTS 같은 하드웨어 흐름 제어를 쓰는 장치는 추가 연결이 필요합니다.

## 통신 설정

양쪽의 전송 속도, 데이터 비트, 패리티, 정지 비트가 일치해야 합니다. **패리티**는 오류 검출을 위해 추가하는 비트입니다. **baud**는 초당 심벌 수이며, 일반적인 이진 UART에서는 초당 비트 수와 같습니다.

`115200 8N1`의 의미:

- 전송 속도: 115200 baud
- 데이터: 8비트
- 패리티: 없음(None)
- 정지 비트: 1비트

일반적인 이진 UART의 8N1 전송은 시작 1비트 + 데이터 8비트 + 정지 1비트로 한 바이트당 10비트가 필요합니다. 연속 전송 시 이론상 약 `115200 / 10 = 11520 byte/s`이며, 실제 처리량은 대기·프로토콜 오버헤드에 따라 낮아집니다.

## UART와 전기 규격 구분

| 이름 | 의미 | MCU 핀 직접 연결 |
| --- | --- | --- |
| 논리 레벨 UART | 3.3V/5V 등의 논리 신호 | 전압·임계값이 호환될 때 가능 |
| RS-232 | 별도 전압·극성을 사용하는 직렬 인터페이스 규격 | 전용 트랜시버 필요 |
| RS-485 | 차동 신호를 사용하는 전기 규격 | 전용 트랜시버 필요 |
| USB-UART 어댑터 | USB와 UART 사이의 변환 장치 | UART 측 신호 전압 확인 후 연결 |

USB-UART 어댑터의 전원 출력 선택이 TX/RX 논리 전압도 바꾸는지는 제품마다 다릅니다. VCC 핀은 통신에 항상 필요한 것이 아니며, 보드에 이미 전원이 있으면 불필요한 전원 연결을 피합니다.

## 바이트 스트림에 메시지 경계 만들기

UART는 애플리케이션 메시지 단위를 자동으로 구분하지 않습니다. 수신 한 번에 메시지 일부만 도착하거나 여러 메시지가 함께 올 수 있습니다.

- 텍스트: 줄바꿈 구분, 최대 길이, 문자 인코딩을 정합니다.
- 바이너리: 시작 표식, 길이, 명령, 데이터, 체크섬/CRC 등을 정합니다.
- 길이 제한과 수신 타임아웃을 둡니다.
- 오류 후 다음 정상 프레임을 찾는 재동기화 방법을 마련합니다.

## 자주 발생하는 문제

| 증상 | 점검 |
| --- | --- |
| 아무것도 수신하지 않음 | TX/RX 교차, GND, 핀 기능, 포트 선택 |
| 문자가 깨짐 | 전송 속도·프레임·논리 전압·클록 오차 |
| 가끔 데이터가 사라짐 | 수신 버퍼 넘침, 긴 블로킹 작업, 흐름 제어 |
| 줄바꿈마다 빈 줄 발생 | CR/LF 처리 방식 |
