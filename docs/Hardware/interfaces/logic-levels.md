# 신호 전압과 레벨 변환

장치가 켜지는 전압과 통신 핀이 허용하는 전압은 별개입니다.

먼저 알면 좋은 개념: [VIH·VIL·VOH·VOL과 노이즈 여유](../glossary/signals.md#논리-신호), [풀업과 출력 구동](../background/pullups-and-drive.md)

## 입력과 출력의 호환성

| 기호 | 의미 |
| --- | --- |
| VIH(min) | HIGH로 인식하기 위해 필요한 최소 입력 전압 |
| VIL(max) | LOW로 인식할 수 있는 최대 입력 전압 |
| VOH(min) | 지정한 부하에서 보장하는 HIGH 출력 전압의 최솟값 |
| VOL(max) | 지정한 부하에서 보장하는 LOW 출력 전압의 최댓값 |

기본적으로 `VOH(min) >= VIH(min)`, `VOL(max) <= VIL(max)`여야 하며 노이즈 여유도 필요합니다. **노이즈 여유**는 출력이 보장하는 전압과 입력 판정 경계 사이의 여유로, 신호가 조금 흔들려도 정상 판정할 수 있게 합니다. 또한 입력 핀의 허용 전압 범위를 넘으면 안 됩니다.

- 5V 출력을 3.3V 입력에 직접 연결하면 손상될 수 있습니다.
- 3.3V 출력을 5V 입력에 연결할 수 있는지는 입력 임계값에 달려 있습니다.
- 5V 내성은 핀·동작 모드·전원 상태에 따라 제한될 수 있습니다.
- GND를 공유해도 전압 수준이 자동으로 변환되지는 않습니다.

## 푸시풀과 오픈드레인

| 출력 방식 | HIGH 만들기 | LOW 만들기 | 주의점 |
| --- | --- | --- | --- |
| 푸시풀 | 출력 회로가 직접 구동 | 출력 회로가 직접 구동 | 서로 반대 값을 내는 두 출력을 연결하면 충돌 |
| 오픈드레인 | 출력을 해제하고 풀업에 맡김 | 출력 회로가 GND로 당김 | 풀업 저항과 연결 전압 필요 |

일반적인 I2C의 SDA/SCL은 오픈드레인 방식으로 사용합니다. 어느 장치도 LOW로 당기지 않을 때 풀업 저항이 선을 HIGH로 만듭니다.

오픈드레인이라고 임의의 전압으로 풀업해도 되는 것은 아닙니다. 버스에 연결된 모든 핀의 허용 전압과 입력 임계값을 만족해야 합니다.

## 변환 방식 선택

| 상황 | 고려할 방법 |
| --- | --- |
| 느린 단방향 5V 출력 → 3.3V 입력 | 저항 분압 또는 적합한 레벨 시프터 |
| 단방향 3.3V 출력 → 높은 전압의 논리 입력 | 해당 입력이 호환되는지 확인, 필요하면 버퍼·레벨 시프터 |
| 양방향 오픈드레인 I2C | I2C에 적합한 양방향 레벨 시프터 |
| 빠른 푸시풀 SPI | 방향·속도·부하 조건을 만족하는 레벨 시프터 |

분압은 입력 부하와 배선 정전용량의 영향을 받습니다. 양방향 버스에 그대로 사용할 수 없으며, 전원을 공급하는 용도도 아닙니다. I2C용 변환 모듈이 고속 SPI에도 적합하다고 가정하지 않습니다.

## 연결 전 확인

1. 보드와 모듈의 공급 전압을 각각 확인합니다.
2. 실제 신호 핀의 허용 전압과 임계값을 확인합니다.
3. 모듈에 내장된 풀업의 연결 전압을 확인합니다.
4. 출력 방식과 신호 방향에 맞는 변환 회로를 고릅니다.
5. 한쪽 전원이 꺼진 상태에서 신호가 들어와도 되는지 확인합니다.
