# 하드웨어 문제 진단

전원 → 배선 → 전기 신호 → 통신 설정 → 데이터 해석 순서로 확인하면 원인을 좁히기 쉽습니다. 한 번에 하나의 조건만 바꾸고 결과를 기록합니다.

먼저 알면 좋은 개념: [GND·전압 강하·도통](../glossary/electrical.md#전압과-전원), [논리 레벨과 임계값](../glossary/signals.md#논리-신호), [전원과 노이즈](../background/power-and-noise.md)

## 기본 도구

| 도구 | 확인할 수 있는 것 | 한계 또는 주의점 |
| --- | --- | --- |
| 멀티미터 | DC 전압, 저항, 도통, 전류 | 짧은 순간의 파형을 보기는 어려움 |
| 시리얼 로그 | 실행 순서, 상태, 오류, 원시 데이터 | 과도한 출력이 타이밍을 바꿀 수 있음 |
| 로직 분석기 | 디지털 신호 타이밍과 프로토콜 | 아날로그 파형 품질은 직접 확인하기 어려움 |
| 오실로스코프 | 전압 강하, 상승 시간, 노이즈, 파형 | 프로브 연결·접지·입력 정격 확인 필요 |

> 용어 풀이: **도통**은 두 지점 사이에 전류가 흐를 연결이 있는지 확인하는 것입니다. **로직 분석기**는 신호를 HIGH/LOW로 해석해 타이밍을 보여주고, **오실로스코프**는 시간에 따른 전압 파형을 보여줍니다.

## 멀티미터 사용 기초

- **전압**: 전원이 켜진 상태에서 측정 대상의 두 지점에 병렬로 연결합니다.
- **저항·도통**: 전원을 제거하고 필요한 경우 커패시터를 안전하게 방전한 뒤 측정합니다. 회로 안의 다른 부품이 저항 측정값에 영향을 줄 수 있습니다.
- **전류**: 전류가 흐르는 경로를 끊고 계기를 직렬로 넣습니다. 리드 단자, 범위, 퓨즈 정격을 확인합니다.
- 전류 측정 모드의 리드를 전원 양극과 GND에 바로 대면 단락이 됩니다. 측정 후에는 리드를 전압 측정 단자로 돌려놓습니다.

## 단계별 진단

### 1. 전원

모듈의 실제 전원 핀과 GND 사이를 측정합니다. 공급 장치 출력이 정상이어도 케이블·접점 때문에 부하 쪽 전압은 다를 수 있습니다.

- 정격 범위에 들어오는가?
- 부하가 켜질 때 전압이 떨어지는가?
- 전원 공급 장치의 전류 제한이 작동하는가?
- 부품이나 배선이 비정상적으로 뜨거운가?

### 2. 배선

전원을 끄고 핀 번호, 극성, 공통 GND, 브레드보드 레일 분리를 확인합니다. 색상만 믿지 말고 각 선의 양 끝을 추적합니다. 의심되는 점퍼선은 도통을 확인하거나 교체합니다.

### 3. 신호

GPIO 출력이나 통신선이 실제로 변하는지 관찰합니다.

- 선택한 핀에서 신호가 나오는가?
- 전압 수준이 수신기와 호환되는가?
- I2C 유휴 상태가 HIGH인가?
- UART TX에 전송 파형이 있는가?
- SPI CS와 SCLK가 올바른 순서로 동작하는가?

로직 분석기도 입력 최대 전압과 논리 임계값을 확인하고 GND를 연결합니다. 오실로스코프의 접지 클립은 보호 접지에 연결된 경우가 많으므로 임의의 전원 노드에 연결하지 않습니다. 접지 기준이 다른 회로는 적합한 차동 측정 장비가 필요합니다.

### 4. 통신과 데이터

주소, 클록 모드, 전송 속도, 바이트 순서, 초기화 순서를 확인합니다. 정상 동작하는 최소 구성에서 장치를 하나씩 추가합니다.

```text
남기면 좋은 로그:
단조 시간 / 장치 식별자 / 현재 상태 / 작업 이름
전송 성공·실패 / 오류 코드 / 수신 길이 / raw 바이트
변환한 값과 단위 / 재시도 횟수 / 마지막 성공 시각
```

## 증상별 빠른 점검

| 증상 | 먼저 볼 곳 |
| --- | --- |
| LED가 켜지지 않음 | 극성, 저항, 출력 모드, active-low 여부 |
| 버튼이 저절로 눌림 | 플로팅 입력, 풀업·풀다운, 배선 |
| 한 번 눌러 여러 번 처리 | 접점 바운스, 이벤트 처리 방식 |
| 센서가 검색되지 않음 | 전원, SDA/SCL, 풀업 전압, 주소 |
| I2C 버스가 멈춤 | SDA/SCL 고정 LOW, 장치 리셋·복구 절차, 타임아웃 |
| SPI 값이 전부 0x00/0xFF | CS, MISO 연결, 모드, 장치 전원·준비 상태 |
| 모터 작동 시 재부팅 | 피크 전류, 전압 강하, GND 경로, 노이즈 |
| 디버깅 중에만 동작 | 초기화 대기 누락, 타이밍 의존, 공유 상태 경쟁 |

## 재현 기록

보드·모듈 모델과 버전, 전원 조건, 배선표, 코드 버전, 기대 결과, 실제 결과를 함께 기록합니다. “가끔 실패” 대신 “모터 기동 시 센서 읽기 100회 중 3회 타임아웃”처럼 조건과 빈도를 남기면 다음 실험을 정하기 쉽습니다.
