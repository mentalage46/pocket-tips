# 샘플링과 측정 오차

먼저 알면 좋은 개념: [ADC와 PWM](../interfaces/analog-and-pwm.md), [변환과 측정 용어](../glossary/signals.md#변환과-측정)

## 시간을 고르는 것과 크기를 나누는 것

샘플링은 신호를 **언제** 읽는지, 양자화는 읽은 크기를 **몇 단계**로 표현하는지에 관한 과정입니다. 샘플링 횟수와 ADC 비트 수를 높이는 것은 서로 다른 문제를 해결합니다.

예를 들어 이상적인 12비트 ADC가 0~3.3V 범위를 사용하면 4096단계가 있고, 한 단계는 약 `3.3 / 4096 = 0.806mV`입니다. 두 입력 전압이 아주 가까우면 같은 코드로 표현될 수 있습니다. 실제 코드와 전압의 대응은 ADC의 전달 함수와 보정식을 따릅니다.

## 해상도가 정확도는 아니다

눈금이 촘촘한 자도 시작점이 어긋나면 정확하게 잴 수 없습니다. ADC에서도 기준 전압 오차, 오프셋, 게인 오차, 비선형성, 노이즈가 결과에 영향을 줍니다.

기준 전압을 3.3V라고 계산했는데 실제로는 3.0V였다면, 이상적인 비례 환산에서도 입력 전압을 실제보다 약 10% 높게 계산하게 됩니다. 이 오차는 ADC 코드의 비트 수를 늘려도 없어지지 않습니다.

또한 `25.00°C`처럼 소수점 두 자리로 표시했다고 정확도가 ±0.01°C라는 뜻은 아닙니다. 표시 자릿수, 코드 한 단계의 크기, 센서의 정확도는 각각 구분합니다.

## 앨리어싱은 왜 평균으로 해결되지 않을까

빠르게 도는 바퀴를 일정 간격의 사진으로 보면 천천히 돌거나 거꾸로 도는 것처럼 보일 수 있습니다. 샘플링 사이에 일어난 변화를 알 수 없기 때문입니다.

```text
샘플링 주파수: 100Hz → 10ms마다 읽음
입력: 90Hz 사인파
관측: 같은 샘플을 만들 수 있는 10Hz 성분과 구별할 수 없음
```

이는 균일한 샘플링에서 가능한 예이며 관측 위상도 영향을 받습니다. 이미 잘못 겹쳐진 주파수 정보는 샘플들을 평균 내는 것만으로 원상 복구할 수 없습니다.

대역이 제한된 신호를 복원하려면 최고 주파수의 두 배를 초과하는 샘플링이 필요합니다. 실제로는 필터가 주파수를 완벽히 잘라내지 못하므로 여유를 두고, 샘플링 **전에** 아날로그 안티앨리어싱 필터로 높은 주파수 성분을 줄입니다. 디지털 출력 센서는 내부 샘플링·필터와 출력 갱신 속도를 확인합니다.

## 보정과 필터링의 역할

| 방법 | 주로 해결하는 문제 | 해결하지 못하는 문제 |
| --- | --- | --- |
| 오프셋 보정 | 일정하게 더해지는 치우침 | 모든 범위의 비례 오차·비선형성 |
| 게인 보정 | 입력 변화에 대한 출력 비율의 오차 | 모든 비선형성·시간에 따라 변하는 잡음 |
| 이동 평균 | 적절한 조건에서의 무작위 흔들림 | 단위 해석 오류·일정한 치우침·이미 생긴 앨리어싱 |

평균을 강하게 적용하면 실제 변화에도 늦게 반응합니다. 측정 목적에 맞는 응답 시간과 노이즈 감소 사이에서 선택해야 합니다. 동일한 센서 값을 갱신 전에 반복해서 읽는 것은 새로운 독립 샘플을 여러 개 얻는 것과 다릅니다.
