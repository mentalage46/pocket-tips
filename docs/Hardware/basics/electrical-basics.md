# 전기 기초

하드웨어 제어는 신호를 바꾸는 코드와 전류가 흐르는 회로가 함께 동작하는 일입니다.

먼저 알면 좋은 개념: [전위·GND·부하](../glossary/electrical.md#전압과-전원), [저항·정전용량](../glossary/electrical.md#저항과-정전용량)

## 기본 물리량

| 물리량 | 기호 / 단위 | 의미 |
| --- | --- | --- |
| 전압 | V / 볼트(V) | 두 지점 사이의 전위 차이 |
| 전류 | I / 암페어(A) | 단위 시간에 흐르는 전하량 |
| 저항 | R / 옴(Ω) | 전류의 흐름을 방해하는 정도 |
| 전력 | P / 와트(W) | 단위 시간에 소비하거나 전달하는 에너지 |

- `1 A = 1,000 mA`, `1 mA = 1,000 μA`
- `1 kΩ = 1,000 Ω`, `1 MΩ = 1,000,000 Ω`
- 전압은 기준점에 대한 값입니다. 보드에서 말하는 3.3V는 일반적으로 해당 보드의 GND 기준입니다.
- DC는 극성이 일정한 전원이며, AC는 시간에 따라 극성이 바뀝니다. 입문 실습은 저전압 DC로 시작합니다.

> 용어 풀이: **전위**는 기준점에 대한 전압 수준이고, 두 지점의 전위 차이가 **전압**입니다. **부하**는 전원이나 신호 출력에 연결되어 전류를 받는 회로·부품입니다.

## 옴의 법칙과 전력

저항에 대해 다음 관계가 성립합니다.

```text
V = I × R
I = V / R
P = V × I = I² × R = V² / R
```

### LED 저항 계산

출력 전압 3.3V, LED 순방향 전압 2.0V, 목표 전류 3mA를 가정합니다.

```text
GPIO ── 저항 ── LED 애노드 → 캐소드 ── GND

R = (3.3 - 2.0) / 0.003 ≈ 433Ω
470Ω 사용 시 I ≈ (3.3 - 2.0) / 470 ≈ 2.8mA
저항 소비 전력 ≈ 0.0028² × 470 ≈ 0.0037W
```

LED 순방향 전압은 색상·제품·전류에 따라 다릅니다. 실제 GPIO의 출력 전압과 허용 전류도 확인해야 합니다. 저항 정격은 계산된 소비 전력보다 여유 있게 선택합니다.

## 직렬과 병렬

| 연결 | 전류와 전압 | 저항의 합성 |
| --- | --- | --- |
| 직렬 | 각 부품에 같은 전류, 전압은 나뉨 | `Rtotal = R1 + R2` |
| 병렬 | 각 가지에 같은 전압, 전류는 나뉨 | `1/Rtotal = 1/R1 + 1/R2` |

두 저항으로 분압할 때, 출력에서 가져가는 전류가 무시할 만큼 작다면 다음 식을 사용합니다.

```text
Vin ── R1 ──┬── Vout
            R2
            │
           GND

Vout = Vin × R2 / (R1 + R2)
```

분압기는 부하에 따라 출력 전압이 달라지므로 모터나 보드의 전원 공급 장치로 사용하지 않습니다. ADC 입력에서도 소스 저항과 샘플링 시간이 측정에 영향을 줄 수 있습니다.
