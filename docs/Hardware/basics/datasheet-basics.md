# 데이터시트 읽기

데이터시트는 부품의 전기적·시간적 동작 조건을 정의합니다. 칩 데이터시트와 그 칩을 실장한 모듈의 설명서는 함께 확인해야 합니다.

먼저 알면 좋은 개념: [정격과 동작 한계](../glossary/electrical.md#전압과-전원), [셋업·홀드 시간](../glossary/signals.md#시간과-파형), [레지스터 접근의 부작용](../background/register-side-effects.md)

## 처음 읽을 순서

| 항목 | 확인할 내용 |
| --- | --- |
| 부품명·리비전 | 정확한 모델, 변형 제품, 문서 개정판 |
| Pin Configuration / Pin Description | 핀 배열, 기능, 극성, 입력·출력 구분 |
| Recommended Operating Conditions | 정상 동작에 사용할 공급 전압·온도 범위 |
| Absolute Maximum Ratings | 넘으면 손상될 수 있는 한계 조건 |
| Electrical Characteristics | 논리 임계값, 출력 구동 능력, 소비 전류, 정확도 |
| Timing Characteristics | 클록, 준비 시간, setup/hold, 변환 시간 |
| Register Map / Protocol | 주소, 설정 필드, 읽기·쓰기 순서 |
| Typical Application | 권장 주변 회로, 커패시터, 저항 |

> 용어 풀이: **setup/hold**는 데이터를 읽는 기준 시점의 전·후에 데이터가 안정되어 있어야 하는 최소 시간입니다. **리비전**은 문서나 제품의 개정 버전을 뜻합니다.

## 정격과 동작 조건을 구분하기

절대 최대 정격은 설계 목표가 아닙니다. 정상 동작은 권장 동작 조건과 전기 특성의 보장 범위에서 설계합니다. 표의 각 수치가 어떤 전압·온도·부하 조건에서 측정되었는지도 읽습니다.

- `Min / Max`: 지정된 시험 조건에서의 하한·상한을 확인합니다.
- `Typ`: 대표값입니다. 모든 부품에서 보장되는 한계값으로 사용하지 않습니다.
- 단위가 `μA`인지 `mA`인지, 시간이 `μs`인지 `ms`인지 구분합니다.

## 공급 전압과 신호 전압은 다를 수 있다

모듈의 VIN이 5V를 지원해도 내부 칩의 통신 핀이 5V를 허용한다는 뜻은 아닙니다. 모듈 회로도에서 다음을 확인합니다.

1. 레귤레이터가 있는가? 어느 핀에 어느 전압을 넣는가?
2. 신호선에 레벨 시프터가 있는가?
3. 풀업 저항이 있다면 어느 전원에 연결되어 있는가?
4. 주소 선택·리셋·인터럽트 핀에 기본 저항이 있는가?

## 통신 예제를 읽을 때

- I2C 주소가 7비트 주소인지, R/W 비트까지 포함한 8비트 표현인지 구분합니다.
- 여러 바이트의 순서가 MSB 우선인지 LSB 우선인지 확인합니다.
- 측정값이 부호 있는 값인지, 몇 비트가 유효한지 확인합니다.
- 읽으면 지워지는 비트, 1을 쓰면 지워지는 비트, 예약 비트를 구별합니다.
- 전원 투입 후 준비 시간과 측정 완료 조건을 확인합니다.

## 기록하면 좋은 정보

모듈 문서에는 제조사 데이터시트 링크, 확인한 리비전, 관련 표·절 이름을 남깁니다. 판매 페이지의 요약 사양보다 제조사 문서와 실제 모듈 회로도를 우선합니다. 알려진 하드웨어 문제는 제조사의 정오표(Errata)도 확인합니다.
