# 로컬 모델 실행

오픈 가중치 모델을 자기 PC나 서버에서 직접 실행하면 데이터가 외부로 나가지 않고, 호출당 비용이 없으며, 오프라인에서도 동작합니다. 대신 하드웨어, 양자화, 서빙 소프트웨어를 직접 다뤄야 하고 상위 API 모델보다 품질이 낮은 경우가 많습니다. 이 문서는 언제 로컬 모델이 맞는지, 어떻게 고르고 띄우고 연결하는지를 다룹니다.

## 언제 로컬 모델인가

| 상황 | 로컬 | API |
| --- | --- | --- |
| 데이터를 외부로 보낼 수 없음 | 적합 | 기업용 계약·리전 옵션 검토 |
| 호출량이 매우 많고 단순한 작업 | 적합(GPU 상각) | 소형 모델 API도 저렴 |
| 오프라인·엣지 환경 | 적합 | 불가 |
| 최고 품질의 추론·코딩 | 부적합 | 적합 |
| 빠른 프로토타입 | 둘 다 | 설정 없이 시작 가능 |
| 실험·학습 목적 | 적합 | - |

## 먼저 기억할 것

- 모델 크기(파라미터 수)와 양자화 수준이 메모리와 품질을 거의 결정합니다. 7~9B 4비트 양자화 모델이 노트북에서 돌아가는 기준점입니다.
- 같은 이름의 모델이라도 양자화·컨텍스트 설정에 따라 결과가 달라집니다. 평가 세트로 확인합니다.
- 로컬 런타임 대부분이 OpenAI 호환 API를 제공하므로, 호출 코드는 그대로 두고 주소만 바꿔 연결할 수 있습니다.
- 한국어 품질은 모델마다 편차가 큽니다. 다국어 모델이나 한국어 특화 모델을 한국어 평가 세트로 비교합니다.
- 모델 라이선스를 확인합니다. 오픈 가중치라도 상업 이용 조건이 다릅니다.
