# Harness

AI에서 **하네스(Harness)**는 모델을 특정 작업에 연결하고 실행 조건을 관리하는 주변 소프트웨어를 뜻합니다. 모델에 어떤 문맥과 도구를 제공하고, 실행을 언제 이어가거나 멈추며, 결과를 어떻게 확인할지 다룹니다. 제품·논문마다 범위가 다르므로 문맥을 함께 봐야 합니다.

## 학습 순서

| --- | --- | --- |

| 2 | [실행 구조와 설계](./runtime-design.md) | 실행 루프, 도구 계약, 문맥 관리, 권한, 재시도와 복구 |

## 두 가지 주요 용례

| 구분 | Agent Harness | Evaluation Harness |
| --- | --- | --- |
| 목적 | 에이전트가 작업을 수행하도록 실행을 관리 | 모델이나 에이전트를 일정한 절차로 측정 |
| 입력 | 사용자 요청, 작업 상태, 도구와 권한 | 평가 데이터, 실행 설정, 채점 기준 |
| 주요 기능 | 모델 호출, 도구 실행, 상태 저장, 종료 판단 | 환경 초기화, 반복 실행, 채점, 결과 집계 |
| 예시 | 저장소를 탐색하고 코드를 수정·검증하는 실행 환경 | 여러 버그 수정 과제를 격리된 환경에서 실행하고 테스트로 채점 |

평가 하네스가 에이전트 하네스를 호출할 수 있습니다. 이 경우 측정 대상은 모델뿐 아니라 프롬프트, 도구, 실행 정책이 결합된 시스템입니다.

## 먼저 기억할 것

- 같은 모델도 제공한 문맥·도구·실행 예산에 따라 결과가 달라집니다.
- 모델이 제안한 도구 호출은 하네스가 검증하고 실제로 실행합니다.
- 모델의 완료 선언과 작업의 성공 여부는 별도로 확인합니다.
- 복잡한 구조를 도입하기 전에 간단한 실행 루프와 대표 과제로 효과를 측정합니다.
