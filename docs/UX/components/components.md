# 컴포넌트 규칙

컴포넌트는 **언제 쓰고, 어떤 상태를 가지며, 어떻게 동작해야 하는지**가 정의되어야 일관되게 쓰입니다. 자주 쓰는 컴포넌트의 선택 기준과 필수 상태를 정리합니다. 시각 스타일은 디자인 시스템이 정하고, 이 문서는 동작과 사용 규칙을 다룹니다.

## 모든 상호작용 컴포넌트의 상태

| 상태 | 필수 | 설명 |
| --- | --- | --- |
| 기본 | 예 | |
| 호버 | 예(포인터 기기) | 상호작용 가능함을 암시 |
| 포커스 | 예 | 키보드 사용자에게 보이는 포커스 링. 제거 금지 |
| 활성(눌림) | 예 | 누르는 순간 |
| 비활성 | 예 | 왜 비활성인지 툴팁·설명 |
| 로딩 | 비동기 동작 시 | 중복 제출 방지 |
| 오류 | 입력 계열 | 메시지와 함께 |
| 선택됨 | 선택 계열 | |

## 버튼

| 종류 | 용도 | 화면당 수 |
| --- | --- | --- |
| 주 버튼(primary) | 화면의 핵심 동작(저장, 결제) | 1개 |
| 보조 버튼(secondary) | 대안 동작(취소, 뒤로) | 몇 개 |
| 3차 버튼(tertiary·텍스트) | 부차적 동작, 밀도 높은 영역 | 제한 없음 |
| 위험 버튼(danger) | 삭제, 되돌릴 수 없는 동작 | 확인과 함께 |
| 아이콘 버튼 | 공간 제한, 보편적 아이콘(닫기, 검색) | 접근성 라벨 필수 |

| 규칙 | 설명 |
| --- | --- |
| 문구는 동사 | "확인"보다 "저장", "예"보다 "삭제" |
| 순서 | 플랫폼 관례 따름. 웹은 주 버튼 오른쪽이 흔함. 한 제품 안에서 통일 |
| 크기 | 터치 목표 44×44px 권장(WCAG 2.2 AA 최소는 24×24px, AAA는 44×44px), 데스크톱 최소 높이 32~36px |
| 링크 vs 버튼 | 이동은 링크, 동작은 버튼. 시맨틱 요소 사용 |
| 로딩 | 클릭 후 스피너 + 비활성, 문구 유지("저장 중…") |

## 입력

| 컴포넌트 | 적합 | 피할 것 |
| --- | --- | --- |
| 텍스트 입력 | 자유 텍스트, 짧은 값 | 선택지가 정해진 값 |
| 텍스트 영역 | 여러 줄 | 자동 높이 없는 작은 영역 |
| 숫자 입력 | 수량, 금액 | 전화번호·우편번호(텍스트로) |
| 날짜 선택기 | 가까운 날짜 | 생년월일(직접 입력이 빠름) |
| 검색 입력 | 목록 필터, 전역 검색 | |
| 파일 업로드 | 드래그 앤 드롭 + 버튼 | 버튼만 |

| 규칙 | 설명 |
| --- | --- |
| 라벨 | 항상 보이는 라벨. 플레이스홀더는 라벨 대체 불가 |
| 폭 | 기대 입력 길이에 맞춤(우편번호는 짧게) |
| 입력 형식 | 자동 포맷(전화번호 하이픈), 모바일 키보드 타입(`inputmode`) |
| 도움말 | 형식·제약은 입력 전에 표시 |

## 선택

| 컴포넌트 | 선택 수 | 선택지 수 | 적합 |
| --- | --- | --- | --- |
| 라디오 | 1 | 2~5 | 모든 선택지를 보여야 할 때 |
| 체크박스 | 여러 개 | 2~7 | 독립적 옵션 |
| 토글 스위치 | 켬·끔 | 1 | 즉시 적용되는 설정 |
| 드롭다운(select) | 1 | 6~20 | 공간 절약 |
| 콤보박스(검색 가능) | 1 | 20 이상 | 긴 목록 |
| 다중 선택 태그 | 여러 개 | 많음 | 선택 결과를 보여야 할 때 |
| 세그먼트 컨트롤·탭 | 1 | 2~5 | 뷰 전환 |

| 규칙 | 설명 |
| --- | --- |
| 토글은 즉시 적용 | 저장 버튼이 필요하면 체크박스 |
| 기본값 | 가장 흔한 선택을 기본으로. 위험한 동작은 기본 없음 |
| 라디오·체크박스 혼동 금지 | 단일=원형, 다중=사각형 |
| 드롭다운 남용 금지 | 선택지 5개 이하는 라디오가 빠름 |

## 표와 목록

| 항목 | 규칙 |
| --- | --- |
| 열 정렬 | 텍스트 왼쪽, 숫자 오른쪽, 헤더는 내용과 같게 |
| 머리글 고정 | 긴 표는 스크롤 시 헤더 고정 |
| 행 높이 | 밀도 옵션(조밀·보통·여유) |
| 정렬·필터 | 열 헤더 클릭 정렬, 활성 필터 표시 |
| 행 동작 | 호버 시 표시 또는 끝 열의 메뉴 |
| 선택 | 체크박스 열 + 일괄 동작 바 |
| 빈 상태 | 안내와 다음 행동 |
| 페이지 | 페이지네이션(위치 파악) vs 무한 스크롤(탐색) |
| 모바일 | 카드 형태로 변환 또는 핵심 열만 |

## 오버레이

| 컴포넌트 | 용도 | 규칙 |
| --- | --- | --- |
| 모달 | 흐름을 끊고 결정·입력을 요구 | 포커스 가둠, ESC·배경 클릭 닫기, 중첩 금지, 작은 작업만 |
| 드로어·사이드 패널 | 문맥 유지한 상세·편집 | 모달보다 긴 내용 |
| 팝오버 | 요소에 붙은 추가 정보·작은 메뉴 | 바깥 클릭 닫기 |
| 툴팁 | 아이콘 설명, 짧은 보충 | 필수 정보를 툴팁에만 두지 않음, 터치에서는 대안 |
| 토스트 | 결과 알림 | 자동 사라짐, 중요한 오류는 토스트 금지 |
| 확인 대화상자 | 되돌릴 수 없는 동작 | [피드백과 상태](./feedback-and-states.md) |

## 내비게이션 컴포넌트

| 컴포넌트 | 규칙 |
| --- | --- |
| 탭 | 같은 수준의 뷰 전환, 2~7개, 현재 탭 명확, URL 반영 |
| 사이드바 | 현재 항목 강조, 접기 가능, 그룹 제목 |
| 브레드크럼 | 마지막 항목은 현재(링크 없음) |
| 페이지네이션 | 현재 페이지, 전체 수, 처음·끝 |
| 스텝퍼 | 단계 수·현재·완료 표시, 뒤로 이동 허용 |

## 접근성 공통

| 항목 | 내용 |
| --- | --- |
| 시맨틱 | `button`, `a`, `input`, `table`을 div로 대체하지 않음 |
| 이름 | 모든 컨트롤에 접근 가능한 이름(라벨, aria-label) |
| 키보드 | Tab 순서, Enter·Space 동작, 화살표(탭·라디오·메뉴) |
| 포커스 | 보이는 포커스 링, 모달 열림·닫힘 시 포커스 이동 |
| 상태 전달 | `aria-expanded`, `aria-selected`, `aria-invalid` |
