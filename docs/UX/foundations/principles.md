# 사용성 원칙

사용성 원칙은 수십 년의 관찰에서 나온 **사람이 인터페이스를 쓰는 방식의 규칙**입니다. 새 화면을 만들거나 기존 화면을 평가할 때 점검표로 씁니다. 닐슨의 10가지 휴리스틱을 기준으로 개발 실무에서 자주 마주치는 형태로 정리했습니다.

## 10가지 휴리스틱

| 원칙 | 의미 | 위반 예 | 적용 |
| --- | --- | --- | --- |
| 시스템 상태 가시성 | 지금 무슨 일이 일어나는지 알려줌 | 저장 버튼을 눌렀는데 아무 반응 없음 | 로딩 표시, 진행률, 저장됨 표시 |
| 현실 세계와의 일치 | 사용자의 언어와 순서를 따름 | "레코드를 커밋하시겠습니까?" | 업무 용어, 자연스러운 순서 |
| 사용자 통제와 자유 | 되돌리기·취소가 쉬움 | 삭제 즉시 영구 삭제 | 실행 취소, 취소 버튼, 휴지통 |
| 일관성과 표준 | 같은 것은 같게, 플랫폼 관례 준수 | 어떤 화면은 저장이 왼쪽, 어떤 화면은 오른쪽 | 디자인 시스템, 플랫폼 가이드 |
| 오류 예방 | 오류가 나기 전에 막음 | 날짜를 자유 입력 | 날짜 선택기, 제약된 입력, 확인 |
| 재인 우선(기억 대신 인식) | 기억하지 않아도 보고 고를 수 있게 | 명령어를 외워야 하는 검색 | 자동 완성, 최근 항목, 보이는 옵션 |
| 유연성과 효율성 | 초보와 숙련자 모두 지원 | 단축키 없음, 일괄 작업 없음 | 단축키, 일괄 선택, 기본값 |
| 미적·최소 디자인 | 관련 없는 정보 제거 | 모든 필드를 한 화면에 | 우선순위, 점진적 공개 |
| 오류 인식·진단·복구 | 무엇이 왜 잘못됐고 어떻게 고치는지 | "오류 코드 0x80004005" | 사람의 언어, 원인, 해결 방법 |
| 도움말과 문서 | 필요한 곳에서 바로 | 별도 매뉴얼만 | 인라인 힌트, 툴팁, 문맥 도움말 |

## 인지 부하

사람이 한 번에 처리할 수 있는 정보는 제한적입니다. 화면은 **결정의 수와 기억할 것**을 줄여야 합니다.

| 부하 종류 | 원인 | 줄이는 방법 |
| --- | --- | --- |
| 내재적 | 작업 자체의 복잡성 | 단계로 나눔, 기본값 제공 |
| 외재적 | 불필요한 장식·정보·선택지 | 제거, 그룹화, 점진적 공개 |
| 본유적 | 이해를 위한 노력 | 예시, 미리보기, 명확한 라벨 |

| 법칙 | 내용 | 적용 |
| --- | --- | --- |
| 힉의 법칙 | 선택지가 많을수록 결정이 느림 | 메뉴 항목 축소, 추천 옵션 강조 |
| 피츠의 법칙 | 목표가 크고 가까울수록 빠르게 누름 | 주요 버튼은 크게, 터치 목표는 WCAG 2.2 최소 24×24px(AA), 권장 44×44px(AAA·Apple HIG) |
| 밀러의 법칙 | 단기 기억은 약 7개 | 긴 목록은 그룹화, 번호는 묶어 표시 |
| 제이콥의 법칙 | 사용자는 다른 사이트에서 배운 관례를 기대 | 표준 패턴 사용 |
| 근접성·유사성(게슈탈트) | 가까운 것·비슷한 것은 한 묶음으로 인식 | 관련 요소는 가깝게, 무관한 것은 멀게 |

## 피드백과 응답 시간

| 지연 | 사용자 인식 | 필요한 피드백 |
| --- | --- | --- |
| 0.1초 이내 | 즉각적 | 없음(상태 변화만) |
| 1초 이내 | 흐름 유지 | 미묘한 표시(버튼 상태) |
| 1~10초 | 기다림 인식 | 스피너·진행 표시 |
| 10초 이상 | 다른 일로 이탈 | 진행률, 예상 시간, 완료 알림, 취소 |

## 점진적 공개

모든 것을 한 번에 보여주지 않고 **필요한 시점에 필요한 만큼** 드러냅니다.

| 방법 | 예 |
| --- | --- |
| 기본·고급 분리 | 고급 설정은 접힘 |
| 단계별 진행 | 긴 폼을 단계로 |
| 문맥 메뉴 | 항목에 마우스를 올리면 동작 표시 |
| 요약 → 상세 | 목록은 핵심만, 클릭하면 상세 |

## 일관성의 수준

| 수준 | 예 |
| --- | --- |
| 시각 | 같은 색·크기·간격 |
| 동작 | 같은 제스처는 같은 결과 |
| 용어 | 같은 개념은 같은 이름("삭제"와 "제거"를 섞지 않음) |
| 위치 | 주요 동작은 항상 같은 자리 |
| 플랫폼 | OS·브라우저 관례(뒤로 가기, 스크롤) 존중 |

## 평가 점검표

| 질문 | 확인 |
| --- | --- |
| 지금 어디에 있고 무엇을 할 수 있는지 3초 안에 알 수 있는가 | |
| 모든 동작에 즉각적인 반응이 있는가 | |
| 실수를 되돌릴 수 있는가 | |
| 오류 메시지가 원인과 해결 방법을 말하는가 | |
| 기억에 의존하는 단계가 있는가 | |
| 같은 기능이 화면마다 다르게 생겼는가 | |
| 키보드만으로 모든 작업이 가능한가 | |
