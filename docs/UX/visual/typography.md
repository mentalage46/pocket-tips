# 타이포그래피

인터페이스의 대부분은 글자입니다. 서체 선택, 크기 체계, 행간, 대비가 **읽기 속도와 피로**를 결정합니다. 한글은 라틴 문자와 특성이 달라 한글 기준의 수치가 따로 필요합니다.

## 서체 선택

| 기준 | 확인 |
| --- | --- |
| 가독성 | 작은 크기에서 글자 구분이 분명한가(1·l·I, 0·O) |
| 한글 지원 | 한글 완성형 전체, 라틴과의 어울림, 굵기 종류 |
| 굵기 | 최소 Regular·Medium·Bold. 가변 폰트면 유연 |
| 숫자 | 표에는 고정폭 숫자(tabular-nums) 지원 여부 |
| 라이선스 | 웹 폰트 사용 조건 |
| 성능 | 한글 웹 폰트는 크기가 큼. 서브셋·가변 폰트·시스템 폰트 검토 |

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| 시스템 폰트 스택 | 로딩 없음, OS에 자연스러움 | 플랫폼마다 다르게 보임 |
| 오픈 라이선스 한글 웹 폰트(Pretendard, Noto Sans KR 등) | 일관된 외관 | 용량, 로딩 전략 필요 |
| 유료 폰트 | 브랜드 개성 | 비용, 라이선스 관리 |

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif;
```

서체는 본문용 하나, 필요하면 제목·코드용 하나까지. 세 종류를 넘기지 않습니다.

## 크기 체계

| 역할 | 크기(예) | 굵기 | 용도 |
| --- | --- | --- | --- |
| 디스플레이 | 32~40px | Bold | 랜딩 제목, 큰 숫자 |
| 제목 1 | 24~28px | Bold | 페이지 제목 |
| 제목 2 | 20px | Semibold | 섹션 제목 |
| 제목 3 | 16~18px | Semibold | 카드·그룹 제목 |
| 본문 | 14~16px | Regular | 일반 텍스트. 모바일은 16px 이상 |
| 보조 | 12~13px | Regular | 설명, 메타 정보 |
| 캡션 | 11~12px | Regular | 표 주석, 라벨. 최소 크기 |

| 원칙 | 설명 |
| --- | --- |
| 단계 수 제한 | 6~8단계. 비율(1.2~1.25)로 생성하면 일관 |
| 역할 이름으로 토큰 | `font-size-body`, `heading-2`처럼. px 값을 직접 쓰지 않음 |
| 상대 단위 | `rem` 기반으로 사용자 설정 존중 |
| 최소 크기 | 본문 14px, 어떤 텍스트도 11px 미만 금지 |

## 행간과 자간

| 항목 | 라틴 | 한글 | 설명 |
| --- | --- | --- | --- |
| 본문 행간 | 1.4~1.5 | 1.5~1.7 | 한글은 글자가 꽉 차 보여 더 넓게 |
| 제목 행간 | 1.1~1.25 | 1.2~1.35 | 큰 글자는 좁게 |
| 자간 | 0 | 0 ~ -0.02em | 한글 큰 제목은 살짝 좁히면 단단해 보임 |
| 단락 간격 | 본문 크기의 0.75~1배 | 같음 | 들여쓰기 대신 간격 |
| 줄 길이 | 45~75자 | 30~45자 | 한글은 글자당 정보량이 커서 짧게 |

## 한글 조판 주의점

| 항목 | 내용 |
| --- | --- |
| 줄바꿈 | `word-break: keep-all`로 단어 중간 분리 방지. 긴 URL은 `overflow-wrap: anywhere` |
| 혼용 | 한글·영문·숫자가 섞이면 기준선과 크기가 어긋남. 서체 쌍 확인 |
| 굵기 | 한글은 Bold에서 획이 뭉개지기 쉬움. 작은 크기는 Semibold |
| 문장 부호 | 전각·반각 혼용 금지 |
| 양끝 정렬 | 한글 웹에서는 단어 간격이 불규칙해짐. 왼쪽 정렬 |

## 대비와 색

| 텍스트 | 최소 대비(WCAG AA) | 적용 |
| --- | --- | --- |
| 본문 | 4.5:1 | 진한 회색(순흑 대신) on 흰색 |
| 큰 텍스트(18px 이상 굵게, 24px 이상) | 3:1 | 제목 |
| 보조 텍스트 | 4.5:1 유지 | 연한 회색을 너무 연하게 쓰지 않음 |
| 비활성 | 예외 | 단, 읽을 수 있어야 함 |

색은 [색상](./color.md), 검사는 [웹 접근성](../../Web/accessibility.md)을 참고합니다.

## 텍스트 처리

| 상황 | 처리 |
| --- | --- |
| 넘침 | 한 줄 말줄임(`text-overflow: ellipsis`) + 전체 내용은 툴팁·상세 |
| 여러 줄 제한 | `-webkit-line-clamp` |
| 숫자 정렬 | `font-variant-numeric: tabular-nums` |
| 날짜·금액 | 로케일 형식([다국어 관리](../../I18N/README.md)) |
| 대문자 | 라틴 약어·라벨만. 긴 문장 대문자는 가독성 저하 |
| 링크 | 색 + 밑줄 또는 색 + 굵기. 색만으로 구분 금지 |

## 웹 폰트 로딩

| 전략 | 설명 |
| --- | --- |
| 서브셋 | 사용하는 글리프만(한글 2,350자 또는 동적 서브셋) |
| `font-display: swap` | 로딩 중 시스템 폰트로 먼저 표시 |
| preload | 핵심 폰트 파일 우선 로드 |
| 가변 폰트 | 여러 굵기를 파일 하나로 |
| 크기 보정 | `size-adjust`로 폰트 교체 시 레이아웃 이동 최소화 |
